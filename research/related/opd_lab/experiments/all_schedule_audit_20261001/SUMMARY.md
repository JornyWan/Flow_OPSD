# Phase66 all → Phase71 all：已执行配方与时间安排审计

2026-10-01，独立 CPU 分析；没有新 GPU、图片读取或封存集使用。

**两版均完整执行全部教师监督；发现明确的时间安排变化，但没有证据把退化归结为新筛选实现错误。旧版也已有文字能力下降。** 本记录解释历史对比的边界，不改变 Phase71 配方、门槛或结果。

## 已核对相同的部分

固定官方 commit `0c85bf0193a6da24bb1f72152b612d353a154999`，资源 manifest、初始 fresh LoRA、环境、数据字节、底座/教师/评测资源相同。1024 个查询的 prompt、noise seed、顺序与轮次相同；两版实际均接受 1024/1024、执行 16 次更新。

底座/候选采样、`.5 mean((Δt × (student−teacher))²)`、评测器等 7 个关键数学文件逐字相同。均固定 LR=3e-4、64 个查询作为 loss 分母、每批 1fit、GenEval 外部专家 CFG1、学生 CFG4.5、Flow10、最终16轮 RAW。每轮 behavior 从当前 RAW 拷贝，EMA 独立维护，不用于本比较的最终部署。旧版没有逐批 LR 日志，恒定 LR 判断来自其冻结执行代码；新版另有16条实际日志。

`source_changes.diff` 保留完整相关源码变化。新增 `constant` 步长规则不修改 optimizer 的 LR；`record_selected_states=false` 与 `record_fit_blocks=false` 禁用额外状态保存/拟合功能。新旧 all 分支均无条件选择通过技术有效性检查的完整教师动作。用两版各1024条缓存候选证据重放两版选择器，全部2048条 mask/目标身份一致；这是选择逻辑验证，不是 GPU 梯度逐位等价证明。

初始64条中有6条时间索引偶然相同，它们记录的12个候选图片 SHA、预测差异和全部A证据完全一致。只读记录，没有打开图片。这个小范围的一致性支持共同起点和采样路径一致，不能证明所有后续状态一致。

## 实际改变了什么

旧版 v2 对每条查询独立决定时间索引；新版 v3 让同任务/模板的两个不同 prompt 共享时间索引，并在9轮块中遍历0–8。这为同数量、同时间的随机对照提供交换空间，同时改变了每批时间构成及跨轮相关性。1024条中913条时间索引变化；虽然 prompt/noise 相同，也不能把这些查询当同一个中间状态。

|截至轮次|旧 all ΣΔt²|新 all ΣΔt²|新/旧|
|---|---:|---:|---:|
|1|1.29431|0.99724|0.77048|
|2|2.85240|2.62401|0.91993|
|4|5.35852|4.66643|0.87084|
|8|9.58234|8.91050|0.92989|
|16|18.53987|17.11859|0.92334|

完整系数总量约低7.67%，首批约低22.95%。这**不是梯度、有效学习率或 Adam 参数移动的比例**，更不能据此说少7.67%系数造成了多少任务损失。`summary.json` 另列每轮、各时间索引、候选教师差异构成的加权 MSE；该量描述当前 behavior 与教师差异，不是固定验证集上的拟合误差。

旧版也在第4轮跌到1/64，而非新日程才出现退化。不同轮的 noise/时间/模型变化，这张表不是固定图配对，也不能替代终点B评测。

独立已完成开发评测：纯底座 / 旧 all / 新 all 的 joint 为9/13/5，OCR为54/28/11，结构为28/63/65，各128题。旧版提高结构并损失部分OCR，新版的结构接近但OCR损失更大。教师任务适配、共享参数更新对文字的影响、采样安排与有限训练下的敏感性仍可能共同作用；一次固定 seed 的跨版本观察不能分离因果贡献。

## 决策

继续完成既定 Phase71 veto−random 主比较，使用同一冻结新日程；历史旧 all 仅作背景。已有 veto−base joint 点估计不满足必要条件，不扩大本配方。

当前证据不支持自动加 fit、扫 LR/CFG、恢复旧日程后宣称修复，或把 unknown 改成另一种标签。后续最缺的是任务匹配的专家/强基线证据，以及完整学生的增益：单个 GenEval 专家在结构任务上的优势不等于联合 OCR 任务上的优势；“不监督已知损伤”也不会约束共享权重在其余状态上的漂移。

本窗口GPU请求额度已满。后续 CPU 工作先整理专家—任务—原生 OPD 配方的已知与缺失证据，再写有匹配对照的下一协议；未提交任何新训练，也不把此方向当成已经证明的解法。
