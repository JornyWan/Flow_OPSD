Question: do terminally verified two-action external-expert targets teach a GenEval-initialized student more effectively than equal-density random targets? This is a small development study, not native DiffusionOPD reproduction, self-distillation, a final benchmark, or sampler robustness evidence.

## Selection and learning

Use unchanged short_correction_verifier_v1; no threshold, image preprocessing or candidate change. Only training-pair evidence enters masks. The eligibility condition is at least6 automatic accepts covering at least2 task families. Fewer accepts stops before training and remains a coverage result. No human labels are used to choose or discard targets. Freeze masks before fitting; development reference labels are not collected until all students and endpoint images are frozen.

Three arms, in fixed order all / random_matched / verified, share exactly the same initial weights, empty AdamW state, scaler and RNG. all uses every120 training pair; verified uses frozen automatic accepts; random_matched uses the same number as verified in each family, with seed280280 and stable per-family seed mapping. Random may overlap verified by chance and is not selected using labels. Each pair supplies both index3/4 targets. Each of8 optimizer updates uses the full240-slot denominator regardless of mask, with no gradient on rejected slots and no added noop preservation targets. The per-slot loss remains .5 mean((delta_sigma×(v_student−stopgrad(v_O)))²). AdamW lr3e−4,betas(.9,.999),eps1e−8,weight_decay1e−4,clip1; no EMA and no behavior refresh within this first cycle. No schedule, radius or LR sweep.

Masked arms have identical active queries and backward counts; all uses more targets and compute. Report this difference rather than claiming fully compute-matched arms. Expected backward queries: all1920, each masked arm16×accepted_pairs. Action metrics cover all240 saved query slots at initialization and after each arm (960 inference queries total); per-arm action metrics are held separate from full-generation evaluation. Save final raw LoRA, student, optimizer/scaler/RNG and every update/counter. Frozen behavior and source G/O adapters must remain unchanged. CPU tests check dense equivalence, mask independence/denominator, actual second-state/suffix, matching without labels, reset/freeze/refresh and split seeds; GPU replay checks real initialization.

## Evaluation and follow-up decision

For all36 development pairs, generate each final student from its own noise-to-image trajectory at all10 steps; initial G and fixed OCR2 references come from collection. Save every trajectory and all180 comparison images (72 references+108 new students). Same prompt/noise/CFG/schedule across students; no chosen best checkpoint, image, seed or development subset. No evaluation student is allowed to call an external teacher or use the frozen old prefix during primary generation.

Hide all5 method identities per case for native512px observation under the unchanged Phase21+ rubric. Freeze all180 observations before joining the key and any automatic development labels. These implementing-assistant labels are provisional, not independent human truth. Preserve unknowns and the initial draft; identical pixels/requirements share labels. Report initial, fixed-O2 and all3 students, complete/text/task/visibility, per-clause known harm, unknowns and paired wins/losses. Primary learning contrast verified-minus-random; verified-minus-initial and verified-minus-all are also required. Bootstrap the18 prompts within family (6/family), retaining paired seeds,20000 draws/seed28028;95% two-sided intervals. Same-image paired unknown-adverse differences are zero. This small development cohort does not establish generalization or low harm risk.

Predeclared engineering continuation criterion (all required): verified complete count at least initial+2; at least random+1; known-harm count versus initial no greater than random or all; mean target MSE over its accepted training queries decreases. Report intervals even if this numerical pilot criterion passes. A pass warrants a refreshed-behavior/new-seed second cycle with separately frozen protocol, not a success claim. A failure warrants the next mechanism diagnostic: apply each learned student's TWO sequential actions from the identical saved development query prefix and finish with frozen initial behavior, then compare to the already saved full-student outputs. No additional updates, candidate search or relabeling in that diagnostic. This tests whether fitting transferred locally but failed through changed full trajectories. Preserve the Phase28 outcome either way.
