状态：CPU准备，未冻结GPU预算、未提交，不是论文主表或有效性结果。

于512。都保留32个分层，每次64查询、每层2个状态，同一个完整梯度累积组。

全部训练prompt一次，不会将某模板的重复抽样冒充更大数据集。日程在runtime严格

batch拆成会产生单例分层的小optimizer batch。

授权。真正optimizer更新可能因空接受批次跳过，必须报告实际更新和有效监督数。
