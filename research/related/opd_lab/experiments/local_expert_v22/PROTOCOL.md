# Phase22 — single action versus a short expert interval

Frozen before any Phase22 image. Question: does extending a fixed teacher intervention from one Euler transition to two provide useful complete-scene repairs that the one-step candidate set cannot provide?

No optimizer, no reward network, no checkpoint selection. Clean SD3.5-M (zero-output rank32/alpha64 LoRA), FlowMatchEuler10, 512px, student CFG4.5, OCR CFG4.5, GenEval CFG1, fp16 forward and FP32 Euler state. Same assets, inference conventions and v2 rubric as Phase21. Generic Experiment optimizer, EMA, method and fixed_teacher fields are unused here.

Per prompt/seed: noop, GenEval at index1 alpha0.5 for one/two transitions, OCR at index3 alpha1 for one/two transitions. Fixed early GenEval single-step is a prespecified comparator in BOTH cohorts; no development ranking over a large grid. OCR differs in start/strength, so cross-expert comparisons do not isolate expert identity; within-expert duration does.

Intervals are recorded in actual shifted sigma: GenEval single [0.9601293,0.9133490], two-step [0.9601293,0.8576923]; OCR single [0.8576923,0.7903683], two-step [0.8576923,0.7072785]. Worker checks the full exact grid. This fixes flow10 only; it does not claim cross-sampler or step robustness.

For every branch start from the same saved behavior prefix. At every intervened step compute behavior and expert on the CURRENT branch state, then action = behavior + alpha*(expert-behavior). After the interval use the same frozen behavior model on the resulting states. Save baseline states/actions/context/sigmas and every branch state/action/behavior/expert. Never attribute the entire interval reward to only its first action. Recompute each branch separately: 6 physical teacher queries per case (3 per expert), not a compute-matched duration comparison. Record exact counters and allocated GPU-hours. A zero-strength two-step branch must reproduce every baseline suffix state and final PNG before any teacher query.

24 new target words and noise seeds, familiar scene templates/classes/backgrounds; 12 development + 12 reserved confirmation, each count/color/relation balanced 4/4/4. Historical-seed exclusion inventoried. One seed per prompt; not a benchmark claim. Both cohorts and all four candidate policies are frozen now. Confirm always runs after freezing all development observations/results, regardless of development outcome; no changing prompts, duration, strength, gate or rubric after looking at development.

Native512 method-hidden assistant review of all 60 images per cohort, frozen before joining key. Provisional implementing-assistant observations, not independent human ground truth. Preserve unknown; every case remains in denominator. Reuse Phase21 complete-scene v2: text AND task AND full visibility. A known harm is a true→false in any field; any unknown in before/after forbids safe acceptance.

Report all five fixed policies (complete count, clause rates, known harms vs noop, unknown count), paired two-minus-one differences for each teacher, text damage separately, raw complete candidate coverage, and safe-repair oracle over {noop,G1,O1} versus {noop,G1,G2,O1,O2}. Oracle uses endpoint labels, not a deployable selection method. Same selection rule as Phase21: no unknown/no known harm/at least one false→true; complete first, number true second, sum of dt² action-MSE third, canonical name fourth. This displacement score is a tie-break, not a likelihood or cross-duration matched trust region.

Engineering gate on confirmation: at least8 known baselines AND expanded oracle adds at least2 complete scenes over single-step oracle. Also show expanded oracle vs prespecified GenEval single-step; a gain only over noop is insufficient evidence of complex selection value. Gate is not statistical significance; oracle safety is partly by construction. Report prompt-paired bootstrap CI descriptively. Even if gate passes, independent label support and an actual verifier/training test are still required; no automatic large-scale training.

Expectations: extension might repair composition too late for one action, but may introduce text damage, redundant changes, or only framing fixes. A null/negative result means this modest duration extension is insufficient, not that all expert correction is impossible. Do not sweep more durations until this finite comparison is reported.

Budget: two sequential single-L40 jobs, each capped15min, at most0.5 allocated GPU-hour total including failures; stop on replay/counter/integrity failure. No automatic retry or other jobs touched. 120 comparison images +2 noop reference images,144 physical teacher queries,0 optimizer updates. Plain OPD training remains necessary for the later learning comparison; these fixed interventions are not that baseline.
