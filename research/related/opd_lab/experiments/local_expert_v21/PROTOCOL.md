# Phase21：统一完整场景目标，先测候选空间

在生成任何本轮图片前冻结。本轮无训练、无 optimizer、无自动 verifier 接受。新候选和暂时盲审只能测量机会，不能称为新方法或自动筛选成绩。旧 Phase20 的规则、标签、结果不改。

## 共同设置与数据

干净 SD3.5-M backbone；新建 rank32/alpha64 LoRA，要求所有 B 矩阵为零，绝不加载 joint128 或其他已拟合学生。flow10、512px、fp16 前向、FP32 Euler 状态；学生/冻结后缀 CFG4.5，OCR 教师 CFG4.5、GenEval 教师 CFG1。teacher LoRA、模型资产、上游和框架来源沿用本地已核验文件并在每个 run 冻结。

24 个新构造提示词/目标词，开发与确认各12，count/color/relation各4。每 prompt 一个新确定性 seed；新词与 joint_pilot_v1 全部词表分离，保存历史 seed 排除清单。开发/确认使用不同目标词及物体条件，熟悉的任务族、对象类、背景和模板仍共享；不声称语义独立、自然图像覆盖或标准 benchmark。旧 test 集不动。生成器和全部24条文本先冻结。

每条轨迹比较索引1/3/5、OCR/GenEval、alpha0.5/1，共12候选，加noop为13张图。候选动作保持旧表达式 `noop + alpha * (teacher - noop)`；只替换当前一步，后续由同一冻结 backbone 生成。共用完整前缀、噪声和后缀模型。保存全部状态、原始专家动作、插值动作、sigma、context、图片和hash。

每个 cohort：156新图、72教师查询、0更新。第一个基线额外用原动作重放 index3 后缀，图像必须完全一致且发生在首次教师查询之前。每组最终预算：behavior990、OCR36、GenEval36、CFG examples2088、decode157、text inputs24、backward0。实际计数逐项检查。每组一个 L40 分配，15分钟上限，总上限0.5 GPU-hour；失败/参考开销都记入 ledger。没有后台无限重试或自动开始训练。

## 观察、选择、对照

使用 REVIEW_RUBRIC.md；文字/物体条件/完整可见性在比较中均作为约束。known false→true 才算修复；任何 true→false 算已知损伤（其他项未知也不能隐藏损伤）；任一基线/候选项 unknown 则不接受为安全动作。包括仅修复可见性的情况。

每组12 case×13视图；隐藏 baseline/教师/时间/幅度/seed/评分，复核全部156图和未知；相同图片与要求的标签一致。冻结所有观察后才 join key。实施助手的盲审是临时标签，不能称为独立人工真值。当前不使用 OCR/GenEval 自动分数，以免把已知存在偏差的评分器当作验证依据。

**冻结标签 oracle**：只从确定安全修复中选择；先完整场景成功，再满足约束总数，再较小的 `dt²*mean((action-noop)²)`，最后候选名排序。无安全修复选noop。该策略读取候选终点标签，是机会诊断，不是可部署选择器。其同标签上的零已知损伤是按规则构造的，不是独立安全性证明。

**强固定候选对照**：开发组比较完整12种配置和noop。排序为完整数高优先、已知损伤少优先、候选unknown少优先、冻结候选顺序（noop最先，其余index→teacher→alpha）破同分。另选开发组零已知损伤的最佳固定策略。报告所有配置，避免只展示胜者；有限网格最佳不等于全局最佳OPD。

保存 `development_results.json` 和其hash后，写 `development_selection.json`，才允许准备/生成确认组。确认组固定对照不可重选，两个对照均从开发组带入；按原计划完整生成确认组，不因开发结果好坏挑选确认提示词或换seed。

## 指标与下一阶段门槛

每策略报告完整数、已知损伤、候选unknown、比较unknown、安全修复数，保留逐prompt数据和所有图像。主比较为确认组 oracle 相对开发组固定策略的配对完整差与损伤差；同时报告noop和开发组零损伤固定策略。prompt bootstrap2000、seed0，12prompt一seed，仅为描述性区间，不代表模型训练或标注不确定性。

预定工程机会门槛：至少8/12基线可确定判读，且 oracle 比主固定策略至少多2个完整场景，或完整数不降且至少少2例已知损伤。两个条件均需满足。该阈值只决定是否值得后续机制拟合，不代表统计显著或自动verifier有效；始终报告实际差值和不确定性。

未通过时，不直接扩大旧样本拟合；按覆盖不足、基线已饱和、候选无修复、未知标签或固定教师已足够等逐项诊断。通过时先确认关键差异有独立复核支持，再规划同起点的普通OPD、随机筛选、验证筛选在线训练；不在此协议中隐式授权自动挑样训练。
