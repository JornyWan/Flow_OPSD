## 1. 去掉正交分量没有恢复收益

令 `delta = selected_target - behavior`，`e = student - behavior`，投影动作为 `behavior + gamma * delta`，`gamma = <e,delta>/||delta||²`。不截断 gamma；每对只去掉 e 的正交分量。

| checkpoint | 实际动作 ΔU | 投影动作 ΔU | 投影 − 实际，95% 配对区间 | 平均 gamma |
|---|---:|---:|---|---:|
| fit2 | +0.145509 | +0.019562 | −0.125947 [−0.241856, −0.034271] | 0.114475 |
| fit2_keep | +0.143236 | +0.052895 | −0.090341 [−0.182585, −0.009465] | 0.112615 |
| fit4 | +0.053042 | +0.029179 | −0.023864 [−0.116098, +0.054361] | 0.208804 |
| fit4_keep | +0.053232 | +0.051527 | −0.001705 [−0.048485, +0.061937] | 0.200798 |

前两个 checkpoint 的投影没有查询变好，分别有 8、7 个变差；后两个的均值差异区间包含零。正交分量占运动平方范数约 66–71%，**并不因此就是有害部分**。本实验不支持直接限制学生只沿所选教师方向移动。

每个 checkpoint 有 1 个负 gamma，没有 gamma>1。投影依赖推理时知道教师目标，是机制诊断，不能直接当作部署方法。

## 2. 完整修正的收益不能按幅度线性缩小

beta 相对于已选目标；目标本身可能是半幅教师动作，beta=1 不一定是完整教师动作。

| beta | 平均 ΔU | 95% 配对区间 | 变好 / 变差 / 不变 |
|---|---:|---|---|
| 0 | 0 | [0, 0] | 0 / 0 / 22 |
| 0.25 | +0.022655 | [−0.021552, +0.083539] | 4 / 2 / 16 |
| 0.50 | +0.043004 | [−0.030389, +0.139650] | 5 / 6 / 11 |
| 0.75 | +0.221792 | [+0.113360, +0.345480] | 12 / 3 / 7 |
| 1 | +0.520656 | [+0.419306, +0.611189] | 22 / 0 / 0 |

8/22 条单独曲线非单调；beta=.5 有 2 个查询损害 noop 原有已满足子句，虽然 beta=1 已经过保护筛选。**完整修正通过终端验证，不保证其中间幅度安全有效。** 25%/50% 幅度只保留约 4.4%/8.3% 的完整目标平均代理收益。

学生沿目标方向平均只移动约 11–21%，与小幅纯目标动作弱收益相容。但 beta=1 本来由同一 verifier 选出，曲线存在选择条件，不能据此证明加大学习率或延长 fitting 有效。前一阶段已经观察到 fitting loss 下降同时正常部署收益不改善。

## 结论边界

目前仍未证明正常采样或跨 sampler/steps 的稳定增益。投影并非有效的简单修法；幅度、生成过程和 verifier 阈值的非线性可能共同作用，监督标签也需校准。以上是 22 个被筛选 TRAIN 状态、单训练种子的条件诊断，prompt 配对 bootstrap 2000 次、seed0，无多重比较校正。
