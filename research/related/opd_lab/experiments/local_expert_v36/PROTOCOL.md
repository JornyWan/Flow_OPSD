# Phase36: frozen tiled OCR coverage experiment

Purpose: test whether additional text regions missed by full-image detection can be exposed without changing recognizer, thresholds or target-word normalization. Use the existing PaddleOCR weights and old four-reading full-image baseline. Tile size384 on native512, four corners at offsets0/128, tile scale2. Every detection/row/crop reading is preserved. Map tile coordinates to original space. Merge repeated extra rows only by geometry (intersection over smaller bbox>=0.8 and vertical overlap>=0.7); never merge by recognized or expected text.

Internal tile edges within8px mark possible fragments. Such a fragment is explained only if it geometrically matches a full-image row extending beyond that same crop edge. Otherwise abstain. Matched complete rows must agree in whitespace-normalized transcription with full-image evidence and crop rereads, at confidence>=0.8. Unmatched extra regions require agreement from two distinct complete tile views plus their rereads at>=0.8 to veto as false. Conflicts, low confidence or unmatched fragments cause unknown; uncertainty takes precedence over hard veto. False/unknown baseline labels are never promoted. This is an additional coverage check, not a new reward or proof of text absence.

Development: ALL350 Phase34 images with frozen provisional assistant labels, including known failures. External reused-data audit: ALL600 Phase33 images,60 prompts,2 seeds,5 fixed model outputs. Check words disjoint from ALL60 Phase34 words, not only53 reviewed prompts. Freeze full list and identities before new predictions. No cherry-picking by error, model, prompt or confidence. External reference labels have historical exposure and are provisional, not new independent human truth. Phase33 model contrasts are not local intervention experiments. No protocol/threshold changes after development or external results.

Use cached full-image OCR for350 development images; replay four fixed hash-ordered cases' baseline verdicts and all normalized reading strings before novel tiled predictions. For external600 compute old full-image baseline and tiled evidence in the same worker. Four CPU workers, one OCR CPU thread each; unchanged models, thresholds and normalization. Retain scorer asset hashes, source snapshots, every prediction, unknown and runtime failure. Images are opened only by local evaluation code; zero direct agent image reads. No diffusion generation, GenEval calls, parameter updates, GPU reservation or external API.

Primary endpoints on external cohort: reference-false predicted-true count/rate, reference-true predicted-false count/rate, predicted-unknown fraction over known-reference images, reference-true predicted-true fraction, full confusion table. Unknown references stay separate. Report all350 development and all600 external results, per-model counts and paired transition counts. Do not select a best model subgroup. Provide95% descriptive paired bootstrap intervals for rate differences, resampling60 prompt clusters within task family,20000 draws seed36036, keeping2 seeds and5 outputs together. Zero denominators undefined. No independent-image binomial inference or confirmatory significance claim.

Fixed screening gate, external only: baseline must have>=4 false accepts; tiled false accepts reduce by>=25%; false-reject rate increase<=0.02; unknown fraction increase<=0.05; true-pass rate loss<=0.02. Rates use all corresponding known references, not only non-abstentions. Passing warrants further independent testing, not new training automatically. If it fails, preserve results and do not relax or retune. Object/visibility metrics are not recomputed or claimed improved.

Predictions freeze before reference-label join. Bounded CPU job45 minutes, no automatic retry/requeue. Run geometry/fragment/extra-text tests before submission. Save compact numeric report and independent verification; no screenshots or image inspection by the coding agent. Previous completed archives stay unchanged.
