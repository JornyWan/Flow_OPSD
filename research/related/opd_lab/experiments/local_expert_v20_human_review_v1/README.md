# Phase20 独立人工复核，第1批

请在浏览器打开[review.html](review.html)。这是主评测完整的12组、48张图，每组4张；每组字母重新排列，模型身份与助手标签隐藏。逐张判断文字、数量/颜色/位置、完整可见性，抄实际文字；允许不确定。整体偏好单独选填，允许并列或都不好。

全部控件未预填。可用上一组/下一组切换，页面尝试在同一浏览器自动保存。点击“下载当前记录 JSON”可随时保存，包括未完成的记录。下载后把JSON放入本项目，告诉助手路径，或直接在对话附上。也可先用文字反馈“第H01组，A…；B…”。

本批是原先预定的全部positive_fresh_seed / single样本，不按结果挑选；尚未包含完整生成及全部32例的损伤复核。用户已见过聚合结果，不能称完全未接触实验；页面隐藏逐图身份与既有标签。新的人工标注作为独立版本保留，原Phase20档案不改。

图片在runs/le20_human_review_001/images，页面的相对路径指向那里；移动或分享时须同时保留这些图片。身份映射单独保存，复核前请不要查看。准备脚本scripts/prepare_phase20_human_review.py不读取助手observations，只用原主评测cohort/path定义选取12组并重新随机排列。
