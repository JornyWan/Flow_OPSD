# 第三阶段之后的候选下一步（未执行）

主线继续是外部专家 OPD。拒绝点的 behavior 回归是保持正则，并不把主监督来源
改成 self-distillation。本文件是看到第三阶段拟合与图像结果后提出的后续方案，
不是本阶段的预声明，也不是已经完成的实验。

## 优先补齐测量可信度

当前 v1 是已编码 OCR/GenEval 子约束的代理指标。完整可见性、标牌样式等提示
要求未全部进入指标；计数/文字也有可见分歧。先在训练/校准图中复核被接受的
teacher/noop 对，区分真实改善、错误通过和歧义。类别不清、剥皮香蕉计数等应
保留不确定，不能强制用实施者自己的判断充当独立真值。

保留旧 v1；任何新规则另命名、在独立校准材料上固定。不得逐例修 validation
规则后再将同一组图当盲测。正式方法比较仍需要独立于实施者的评价。

## 用已保存的状态诊断方向和幅度，先不增加训练

设冻结 noop 动作为 b，已选择的专家修正为 δ=a_target−b，训练后实际动作为
b+e。计算 γ=(e·δ)/||δ||² 和正交残差 e_perp=e−γδ。只用现有 22 个接受查询，
其 state/context/target 和各 checkpoint 都已经保存，不重新筛目标。

下一份正式 protocol 可以比较以下动作，全部使用原冻结 behavior 完成后缀：

1. b 与 b+δ：重新核对原始基准/目标的可重现性。
2. b+βδ，β∈{0.25,0.5,0.75}：目标方向本身的中间幅度是否改善终点？
3. b+γδ 与 b+e：去掉实际更新的正交分量后，终点是否更好？

同时保留四个原定 checkpoint，不按验证集挑一个赢家。γ 使用实际投影并记录
是否超出 [0,1]，不能悄悄截断后仍称为原投影。重复使用旧图片/得分前必须核对
重新生成的一致性；新图、分数和成本单列，不能混算成新增训练 seed 的证据。

这能区分三种可能，均不可在实验前当成已确认原因：

- 纯目标路径的中间幅度已有收益，实际动作却没有：正交偏移/方向不一致值得查。
- 只有接近完整专家修正才改善：小幅学习可能跨不过图像或评分阈值。
- 原目标收益经复核不可靠：优先修测量，继续拟合会强化错误目标。

当前三范数推导的投影/余弦只是事后描述，不能替代上述终点干预。目标 MSE
下降不证明沿真实效用上升方向移动；保持 MSE 下降也不证明约束被保留。

## 何时再训练、再查跨网格

先得到可重现的真实目标收益及可解释的局部拟合信号，再定义新的短 on-policy
对照和独立训练 seeds。若改变 fitting 次数，应分别报告新查询预算、实际更新
数和 GPU-hours，不能同时声称查询预算与优化预算都相同。保留 compute-matched
原始 OPD/简单筛选对照；固定 checkpoint 续训时从同一 checkpoint 继续 baseline。

之后再扩展多 steps/solver 后缀验证：按 sigma 对齐并正确恢复 DPM 历史，评价
始终使用普通学生生成。当前 flow10/flow40 小型 probe 和训练单 seed 不足以宣布
跨 sampler 稳定增益。锁定 test 继续保留。
