# 重新审视原始 idea 与下一步优先级

2026-09-12。重新阅读两份最初的完整讨论、phase1–6结果、当前方法代码、固定上游OPD训练循环，以及旧Q/OPSD审计后形成。**本文件是研究决策，不是新实验结果或已冻结的GPU执行协议。** 它调整phase6/NEXT的执行顺序：不再把扩展通用审查器作为恢复方法实验的前置主线。旧实验、数据、标签、评分和阶段结论不改。

## 保留的问题，重新验证的假设

目标仍是：同一图片中的多项要求存在冲突时，利用外部专家提出修正，验证其终点是否修复错误且保留已正确内容，再把修正学进单个学生，普通推理不做专家搜索。信息来自外部教师，属于OPD路线。

它要求三个条件同时成立：

1. 在完整查询分布上，可靠选择相对认真调过的固定教师/时间/幅度有实质额外空间。
2. 被选动作或动作序列可由学生的参数更新学会，而不只是执行一次oracle动作有效。
3. 更新后的学生在自己实际访问的状态、整个生成过程及新prompt上保留收益。

当前只观察到一些可信局部修复和一些附带损害，没有闭合这三个条件。工程阶段完成不等于研究假设通过。

## 我们目前偏离原始路线的地方

原始建议是“先保留能训练起来的OPD，再隔离教师监督的选择”。当前`method.py`确实保留了确定性transition loss，但**loss一致不等于训练recipe一致**：

- 四条phase2训练从新rank32/alpha64 LoRA开始，`initial_adapter=null`，并非已经学好多能力的OPD学生。
- 当前局部引擎每条轨迹抽一个状态；原上游`train_sd3_opd.py`对多个训练时间步提供教师监督。筛选还使监督更稀疏，候选在不同专家之间切换。
- 12次在线更新与2/4次固定拟合主要是短程诊断。我们没有先在这套干净框架内展示“普通OPD可充分学会当前教师”的正向学习对照。
- phase3已经测试过拒绝点noop保持，不能把“加保持loss”重新当成未试过的万能解法。它减小了预测偏移，却没有可靠保护整轨迹。
- phase5/6的测量排查有必要，但继续修Qwen格式、裁切和小字，会让研究逐渐变成审查器工程。原始方法的可学习性没有因此自动得到检验。

另外，GenEval教师CFG=1、学生CFG=4.5是当前及上游的显式设置。teacher-copy正向对照必须区分CFG匹配与原配方：只有同模型、同CFG时，复制教师LoRA才构成完全相同预测的可表示性检查。不能用两个不同CFG的输出差声称网络容量不足。

## 立即优先做一个有限的可学习性实验

不先升级reward或扩大训练矩阵。固定当前flow10、现有模型/precision、原始loss及一个初始checkpoint，按下列顺序检验。以下预算是拟定的工程检查上限，开跑前仍需按实际目标清单冻结完整协议。

### A. 正向学习对照

先确认现有OCR/GenEval教师在新框架、相同prompt/分辨率/采样条件下确实有相关能力；同时记录教师原CFG与CFG匹配对照，以及不加载教师、只改变CFG的对照。完整教师生成可回答“教师有无能力”，不能替代局部干预。

在单一教师、明确时间区间和简单单任务上，让普通OPD学生学这个教师。若普通监督都不产生可复现学习，先修优化/数据/CFG/训练覆盖，不能把失败归罪于gate。这个正向对照不替代完整论文数值复现。

### B. 一个目标能不能学会

从已有图片里固定一小批清楚修复、无明确附带损害的状态—目标对（最多16，数量不足就如实报告），保留全部候选和人工可复核的图片。当前实施者标签只能称临时观察；真正独立复核有助于确认含义。

这些有意选择的正例只用于学习能力检查，**不用于估计oracle机会率或方法泛化**。原始评分不改，明确记录另一个诊断清单。

先对每个状态单独拟合，再把同一批状态合起来拟合。teacher、behavior、目标和查询固定，记录1/4/16/64/128更新的曲线；不在128步仍远未拟合时自动加预算。更新只做局部反传，终点图在预定检查点生成。相同训练内小集合最多两档预声明LR，避免无界调参。

报告逐状态的相对target MSE、方向投影、实际同状态干预图，并直接复核所修复的具体内容。工程通过目标可设为：大部分状态MSE下降至少95%，且至少80%的清楚修复在实际学生动作下仍保留；这不是统计显著性门槛，也不意味着剩余小MSE必然保护离散正确性。达不到时定位原因，不修改通过标准。

### C. 把变化发生的位置隔离

若单点/小批量拟合成功，再比较：仅在被测时间位置执行新学生、其余用冻结behavior；在预定短时间区间执行新学生；全程执行新学生。这是诊断，不是三个可以挑最优部署数的模型。

这一步直接区分“动作没学到”和“动作学到了，但其他时间的参数共享变化抵消了收益”。已有同状态单步与完整生成测量可复用；只有充分拟合后做这个对照，才更接近回答后一个问题。

## 如果单步监督不够，最值得尝试的结构性改动

**验证并蒸馏短噪声区间内的专家策略，而不是只给一个孤立大动作打标签。** 这是待验证方案，不是已经有效的新算法。

令候选在区间I内使用`v_b + alpha*(v_T-v_b)`，其余时间用冻结behavior。候选是一个在状态上可重新执行的规则；每步都在该分支自己的状态上查询教师。先测单步与2–4步等长度的短区间，给固定策略同样的候选长度与成本。

对区间结束后的同一behavior continuation做终端验证。接受后保存**整个被接受区间的状态—动作序列**，监督所有实际介入步骤。不能用多步修复的好图给第一步velocity授予全部功劳，也不能把“早期GenEval、晚期OCR”的直觉直接当成已验证流程：phase1晚期OCR的一步效果很弱。

这有两个可检验的好处：增加一致的监督覆盖；让语义修正跨过离散阈值时不必依靠某个孤立步上的大冲击。它也可能更贵、引入更多状态漂移，因此必须比较，不能预设成功。

优先正常学生实现。仅当实验C确认区间外漂移是主要损失，再比较在固定backbone上训练按sigma启用的残差LoRA，使区间外严格使用原模型；这是显式架构变体，所有控制臂都需匹配。LoRA权重的缩放并不等于速度场的线性插值；不能把需要两次forward的速度混合作为一forward实现来计费。若要最终导出普通无门控学生，需另外蒸馏并重新检查收益，不能省略这一步。

## 怎样回到可靠的整体提升

1. 先处理“计数+目标文字”等较简单双约束，保留单能力回归检查。新任务定义、prompt池与旧严格v1分开版本化；不能删除旧任务中的额外文字/裁切要求后，把新分数当作旧任务提升。
2. 建立普通OPD正向学习后，可以从同一个已学好的学生checkpoint分叉；原OPD继续训练必须作为对照。不要只让新方法享受更强初始化。
3. 至少比较最佳固定教师/时间/幅度、接受密度与时间分布匹配的随机筛选、终端验证筛选；再加获得同样教师与reward信息的OPD+NFT，以及同候选赢家整图SFT。后两者在框架内尚未完整实现，不能假装已有。
4. 保留on-policy刷新；当前代码已有这一机制，不把它重新包装成贡献。短区间分支状态的拟合与更新学生实际访问的状态仍须分别验证。
5. 固定训练内probe监测实际拟合后的整轨迹收益，validation用于预定开发选择，锁定test最后使用。评价不在运行时使用教师、搜索或按每张图选择checkpoint。报告训练seed变异、质量/多样性和全部GPU成本。

## sampler/steps问题怎样处理

“只改第k步”随网格变细改变了干预的实际持续时间。若速度差有限，一次Euler干预的直接latent变化为`h*delta_v`；细网格下这个量可能变小，但整条新策略的收益还取决于每步动作、状态及误差传播，不能从这条式子解释所有旧Q曲线。

短区间应按实际sigma范围定义，先在一个接近部署的设置建立学习，再对flow20/40及DPM2做原生轨迹测试。跨多步solver分支必须携带其完整历史；已有flow状态上换suffix只是混合路径诊断。不同网格覆盖区间边界可能不同，需明确记录实际范围、NFE和控制臂。

候选若只在一个网格有效，才启用多网格平均收益/逐配置非退化约束等选择方案；平均增益不保证每种solver都改善，最差项规则也可能过度拒绝。数据、权重、容忍度必须提前固定。**小幅目标、连续sigma区间和多sampler验证都没有自动稳健性保证。**

## 明确的停止或转向条件

| 看到什么 | 下一步 |
|---|---|
| 独立复核的完整诊断集上，动态选择不比最佳固定策略有实际空间 | 停止复杂selector主线，不用有偏已接受子集继续证明空间 |
| 单个目标都无法充分拟合，正向教师对照也失败 | 修训练recipe/实现；不继续增加候选/verifier |
| 单个能学、小批量学不动 | 查跨样本/跨教师监督冲突，再考虑更一致区间或初始化；不先加所有loss |
| 小批量与同状态干预成功，全程生成失败 | 查未监督时间与新状态上的漂移；按需测试区间限定残差与更密集监督 |
| 单步机会弱，2–4步有清楚净收益 | 转短区间完整序列蒸馏，并计成本 |
| 只有近乎全程教师接管才有效 | 承认局部方法空间弱；比较普通专家蒸馏/赢家整图训练 |
| 充分拟合后仅训练样本变好 | 查数据规模、状态覆盖和泛化，不称方法已work |
| 主部署设置成立，但细网格/其他solver丢失 | 再投入多网格原生轨迹与区间定义；不提前重开Q critic支线 |

当前最推荐的下一项工作是A+B的正向学习和可学习性检查，并复用C的已有评测接口。我们首先需要一条可审查的证据链：**清楚的专家修复→充分学会该修复→实际整轨迹保留→新prompt也改善**。不能靠连续增加模块保证最后一个箭头成立。
