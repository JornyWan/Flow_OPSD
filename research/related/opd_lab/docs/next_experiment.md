# 下一实验：接受/拒绝教师修正，是否值得学习？

设计日期：2026-09-22。状态：研究设计；尚未生成新数据、提交GPU或训练。
本文件细化[论文主计划](paper_plan.md)的下一步，优先于其中P2的暂定样本数；不改写任何旧实验协议。

## 1. 决定与依据

下一主实验回答C1：**同一个学生、同一个专家、同一个短窗口，逐状态接受/拒绝专家修正，能否超过开发集选定的固定策略？** 有足够信号后，立即接一轮受控蒸馏检验C2，不再开展一串独立的评分器微调。

当前不能把HPS/ImageReward上升解释成联合任务已经解决，也不能把教师修正图好看解释成学生学会。需要连起来检查三个量：

1. 目标动作直接介入后的终点收益。
2. 学生拟合后，在相同冻结后缀中介入学到的动作，能兑现多少收益。
3. 学生独立正常生成，在新提示词上的联合成功率。

这次重新统计了Phase34全部120例的旧自动结果，没有读图或改标签：

| 旧自动完整场景口径 | 明确成功数 / 120 |
|---|---:|
| 原行为 | 65 |
| 始终早期全幅修正 | 73 |
| 事后在原行为/早期全幅中选成功者 | 78 |
| 再允许早期半幅 | 79 |
| 允许旧实验全部五种动作 | 83 |

这不是已实现选择器的成绩，也不是人类真值上的上限：同一有误差的评分器参与了事后选择。它只提示，在这个已暴露候选库里，二选一保留了不少可见机会，半幅额外机会很少。应先验证最简单的接受/拒绝，而非增加候选数。
数值与源文件SHA见[规划诊断](../experiments/planning_20260922/candidate_opportunity.json)。旧口径包含full_visibility；新实验的语义主指标不与它直接拼表。

## 3. 新候选实验的冻结设计

| 项 | 设定 |
|---|---|
| claim_id | C1；局部选择的增量价值 |
| 学生/专家 | 发布DiffusionOPD Student LoRA / 单个OCRTeacher LoRA；具体权重先核验冻结 |
| 协议 | SD3.5-M，512，确定性Flow/Euler 10步；学生和教师CFG均4.5；模型精度FP16、latent FP32，精度在smoke后固定 |
| 开发候选 | noop，以及开始索引{1,3} × 连续步数{1,2}的四条全幅OCR修正；索引从0开始，alpha=1 |
| 确认候选 | noop + 开发集选定的唯一专家路线T*；共两条终点分支 |
| 唯一机制差别 | 相同T*与查询状态，始终使用，还是根据终点评价接受/拒绝 |
| 开发集 | 48提示词 × 2固定seed，四任务族各12条 |
| 确认集 | 192提示词 × 2固定seed，四任务族各48条；一次固定样本，无看结果后扩样 |
| 任务族 | 文字+数量、文字+颜色、文字+关系、文字+至少两项结构要求 |
| 数据隔离 | 开发/确认拆开文字、模板和对象组合；旧熟悉产品模板只作开发参考；确认提示词及约束在生成前冻结 |
| 新图上限 | 开发480 + 确认768 = 1248张；smoke额外最多8张；共享前缀/原行为终点 |
| 直接助手读图 | 0；本地固定机器评分，缓存逐图证据 |

开发集按预声明的任务主指标选出最好的非noop路线T*；并列取更短、再取更早。另在noop与T*中选出开发集最佳固定策略C_fixed，并列取noop。确认集主要比较是verified减C_fixed；始终T*与noop的结果也全部报告，不从确认集重新挑主要对照。

开发选择指标使用下面的B任务指标，路线不按选择器接受率挑选；确认集的B标签不参与T*、threshold或winner选择。这里的“最佳固定”仅限声明的四条路线与noop，不声称全局最优。

每个案例保存同初始noise、同前缀、同sigma网格；noop和T*干预后均由同一个冻结学生完成后缀。两步路线的第二步在自身实际到达状态重新查询并保存动作。选择器不改变时间、幅度或教师身份。

这是比旧S1/CFG1更接近论文拟定共同起点的新研究设置。与旧阶段同时改变了起点、分布和CFG，所以不作跨阶段因果归因；机制因果比较仅发生在本实验内部。

## 4. 选择、评测和非循环证据

**选择A：**沿用EvidenceVerifier的固定文字/对象证据生成器，不引入新的OCR模型或阈值搜索。对提示词逐项声明的语义约束，T*必须至少修复一个明确false→true，所有已正确要求保持true，且两端声明约束均有明确判断；否则回退noop。运行错误和语义unknown分开保存。full_visibility代理单列；只有提示词明确要求的可见性才进入该样本语义判定，不能把“检测缺框”叫真实物体消失。这是前瞻性的新规则版本，不能回写旧结果。

**评测B：**固定上游原图GenEval逐项strict判定 + 原图OCR完整目标字符串exact-match组成新的自动联合任务指标；同时报告原生OCR reward、字符错误率和每项成功率。exact-match的规范化、额外文本处理、空OCR与运行失败语义须在运行manifest中明确固定。原生reward不悄悄变成exact-match，也不把自定义联合prompt称为官方GenEval benchmark。

A与B共享部分检测/OCR权重，不能称模型独立的验证。A上的选择改善主要是内部诊断；B上的改善仍可能受共同误差影响。独立参考采用**生成前固定抽出的24个确认提示词、保留两个seed，随机左右盲评noop与T***，共96张已有图，无额外生成。根据这同一组独立标签计算所有策略的结果，不只看接受案例。若没有收到人类答案，则该栏记pending，不能据此宣称真实视觉收益已确认；不让助手或远程视觉API代填。

报告内容：

- **主要：**全384案例的语义联合成功率差verified−C_fixed；unknown保留，并报成功下界、可能上界及配对不利敏感性。不能把unknown真的标作错误。
- **损伤：**相对同案例noop，原来明确正确要求被破坏的比例，注明条件分母；另报完整成功→失败、修复、未知和系统错误。
- **选择机制：**接受率；根据B事后看候选机会及漏选/误选，明确不是可部署oracle成绩；报告所有样本。
- **随机控制：**同一T*，按任务族匹配verified接受数量的随机mask。用缓存端点评估固定随机种子的多次mask及期望，不新增图片；它是事后接受量匹配的机制控制，不能充当在线算法效率基线。
- **质量：**同批图PickScore、CLIP、HPSv2.1、Aesthetic、ImageReward全报；标注尺度、截断。它们是本批自定义分布结果，不是DrawBench成绩。
- **不确定性：**按提示词整簇、任务族分层bootstrap，两个seed不当独立prompt。一次主要比较95%区间；其它比较描述性，不挑显著项。
- **成本：**学生/专家前向、suffix NFE、decode/评分、GPU-hours及失败成本。这里只测候选策略，尚无部署效率结论。

192个确认prompt是受成本限制的机制实验，不保证检出5个百分点。历史60个prompt的一个OCR模型对比中，配对prompt均值SD约0.312，48个prompt的粗略95%半宽约8.8pp；该方差既不是新任务联合成功的方差，也不构成正式功效计算。正式论文样本量须根据本轮簇级方差单独预定。

## 5. 看完结果后只允许这些决策

本轮把**联合成功增加5个百分点**作为是否值得扩大复杂选择的工程目标，不是从旧结果得出的预期增益。不能据旧数据上限约4.2pp声称新学生也只能提升4.2pp。损伤指标必须同时报告；“无显著差异”不等于保持安全。

| 结果 | 下一决定 |
|---|---|
| 连候选事后机会也很小，或主要差异区间上界低于5pp | 当前单专家/短窗口设置不支持投入复杂选择；保留固定策略基线，不继续加半幅/更多评分器 |
| 有候选机会，A选择后B不改善或出现可确认损伤 | 选择可靠性不足；最多另立一次有明确假设的选择规则实验，不能直接扩大训练 |
| B点估计≥5pp且主要区间下界>0，未知敏感性不推翻方向 | 有理由做下面一次小规模学习兑现实验；独立盲评缺失时仍标作proxy-positive，不宣布C1已证明 |
| 区间同时覆盖0与5pp | 证据不足；本轮不追加样本、不扩大训练。根据估计方差判断一项新的独立确认是否值得成本 |

人类盲评若明确反驳机器方向，应停止把该机器方向当成功；小规模盲评没有发现问题也不等于全体通过。CI是对固定评分口径的抽样不确定性，不包含评分器系统偏差。

## 6. 满足条件后紧接的学习实验，不再重新发散

先用**独立训练prompt**采一轮共享冻结候选池，T*、A与训练参数已固定；不用上述确认集拟合或选checkpoint。四臂为：始终蒸馏T*、匹配随机接受、验证接受、廉价轨迹reward加权蒸馏；共同初始化、数据顺序、OPD transition-mean loss和优化器，候选池成本全部记录。包含noop共同起点。拒绝槽位mask为0，分母用预定槽位，零监督批跳过optimizer/EMA；不默认加retention。

拟合仅做一个预定短周期，依次评测“目标介入→学到动作介入→正常完整生成”。独立的新确认prompt和checkpoint时点在训练前固定，样本量使用上一轮方差与新的成本上限拟定。这个共享池实验只验证选择信息与可学性，不宣称在线算法或同GPU-hours效率。

若目标收益不能被拟合动作兑现，检查目标表示、梯度/权重和可学性；若拟合动作有效但正常生成无效，才单独研究刷新频率或一种保持方式。不要在两个问题都没区分时一起调学习率、保持、候选和时间分布。

随后正式短程比较加入**原版OPD继续训练**，各臂独立运行自己的3轮behavior刷新并保留optimizer/EMA状态；native基线与同联合任务适配分别命名。每个方法允许在相同总算力内按自身真实开销训练。更强NFT/OPD+NFT、赢家整图SFT和完整标准基准、多训练seed在C1/C2后按论文主计划推进。

以上后续训练仍需单独冻结训练样本、拟合步数、资源上限和确认协议；当前文件没有把它们冒充已运行实验。当前可立即执行的是补齐旧任务指标，以及实现/冻结上述最小候选实验。
