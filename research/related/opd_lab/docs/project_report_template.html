02 / Method

终点验证的局部专家蒸馏

同一张图同时需要正确文字与计数、颜色或空间关系。单任务专家可能修好一项，却损坏另一项。我们比较的是同一个学生状态上的不同动作，经过相同后续生成后，究竟改变了什么。

01 · 冻结当前学生 → behavior

一个采集与拟合周期内保持冻结，建立共同参照。

02 · 分支原动作 / 专家动作

OCR、GenEval专家提供候选；保留原动作作为对照。

03 · 完成生成介入一步，同一后缀

相同初始噪声、状态、网格与冻结后续模型。

04 · 验证修复错误，保护已有正确项

逐项记录文字、物体约束及可见性；保留未知。

05 · 拟合局部动作 → 学生参数

目标detach，使用OPD式transition-mean loss。

动作与训练目标

vcandidate = vbehavior + α · (vexpert − vbehavior)

ℓ = ½ · mean[(Δσ · (vstudent − vtarget))²]

保留时间步Δσ权重。训练loss和诊断用的相对velocity MSE含义不同；报告不会把两者混称。

四层证据分别报告

  1. 候选动作是否产生真实修复机会。
  2. 选择器是否可靠地选中它。
  3. 参数更新是否学会该动作。
  4. 学生普通完整生成是否在新状态上改善。

事后oracle、训练目标MSE和最终部署能力属于不同证据层。

通用方法与近期实验的区别

初版在线引擎由OCR/GenEval评分器筛选，拒绝查询loss为零。近期Phase20为隔离机制，简化为固定状态、单一GenEval教师、助手标签辅助选择，并对拒绝状态施加原动作保持损失。下一轮正要消融这一保持项。

本方法的信息来自外部专家，属于OPD方向。OPSD的reward-gradient self-distillation是另一个训练路径；当前没有训练Q critic，也没有实现无教师候选自改进或shadow-update目标选择主实验。

初版选择器的具体定义与局限

U = η·all(bj) + (1−η)·mean(rj)。候选必须保留原终点已满足的每项约束，并超过预设效用margin；同分优先选择更接近原动作的目标。筛选器自己的效用增益存在选择偏差，不能作为独立质量证明。近期标签辅助的“安全修复”要求明确的false→true，且不出现已知损伤和比较未知；certified只是变量名，不代表形式化保证。

03 / Experimental design

用匹配对照回答“筛选是否有价值”

Phase20监督采集

同一初始学生、6个正提示词、48个固定状态；单一GenEval专家、flow10、query index 3、α=1。

9个接受目标由冻结助手标签确定，覆盖5/6个提示词。人工复核本次没有重新验证这9个训练目标。

训练与评测

  • 三组从同一joint128检查点出发，各128次更新、1536次反向查询。
  • 相同优化器起点、目标、时间与CFG设置；验证选择与匹配随机保持相同教师访问数。
  • 32个prompt/seed组合：正提示词12、保护提示词12、未拟合提示词8。
  • 每组分别测一次动作替换与普通完整学生生成；保存全部256个观察槽。
控制臂正状态上的监督独立保护状态回答的问题
初始 joint128无本轮训练—改善的参照
全部教师 all_teacher全部48状态用教师目标保留原动作是否需要选择监督
验证筛选 certified9状态用教师，其余39用原动作保留原动作标签辅助选择的额外价值
匹配随机 random_matched按原随机匹配选择，教师次数相同保留原动作收益是否只是监督稀疏化

单步路径：沿初始学生到达共同状态，只替换一次被测模型动作，其余由初始学生完成。用于隔离局部动作迁移。

完整路径：由被测学生正常完成整条生成轨迹，推理不使用教师或候选选择。用于检查实际策略效果。

两条路径预先分别报告。主检验为正提示词新seed的单步结果，不能用更好看的次要路径替换。12例仅对应6个长期开发提示词；seed是新的，提示词并不独立未见。未拟合子集也不是整项研究从未接触的正式锁定测试集。

08 / Interpretation

我们知道什么，仍不知道什么

已有证据

存在具体的专家修复机会

部分同状态候选改善了一项约束并保留其他项，但机会有限，且标签仍需可靠复核。

动作可拟合，迁移没有闭合

训练目标误差下降与同seed修复均出现过；新seed和普通生成中的收益不稳定。

测量误差会改变结论

自动verifier、视觉语言模型及助手判读均有局限；独立人评降低了旧成功数字的确定性。

需要实验区分的解释

保持约束过强？

拒绝状态原动作漂移很小，与过强保持相符；但查询数比例并不等于梯度贡献，尚未因果确认。

目标与状态覆盖不足？

Phase20只接受9/48个状态、覆盖5/6提示词；旧状态的修正可能不适用于新状态。

选择本身有没有额外价值？

必须优于匹配随机与全部教师等控制臂，不能靠比初始好或事后oracle来回答。

Phase19图展示全部两例满足当时“教师安全完整、学生明确不完整”的机会；依据助手冻结标签，不是独立人工真值。涉及文字间隔等判读边界，不据此估计总体机会率。

最初的研究问题仍有意义；当前实现尚未证明方法有效。

当前证据不足以推出“多训练一定会好”“换更强judge即可解决”或“失败根源就是sampler变化”。跨采样配置的问题应在一个部署设置先有明确收益后再独立验证。

09 / Next experiment — proposed, not run

先检验一个最小、可归因的改动

未接受教师修正，不自动等于原动作值得作为强监督。下一轮只移除被拒绝正状态上的保持损失，保留原接受目标与独立保护状态。

一次128更新训练的反向查询构成

接受目标：144拒绝状态保持：624独立保护：768

条形位置保持原1536次预算作为参照；移除部分以斜线表示。这里演示计算结构，不能预测reward。保持目标原占90.6%的查询数，不代表90.6%的梯度贡献。

拟议版本目标选择拒绝正状态独立保护
certified_masked保持原验证选择不计算损失保留
random_matched_masked保持原匹配随机选择不计算损失保留

保持起点、学习率、优化器、128次更新、批次槽位与原损失分母；核验跳过forward对随机序列的影响。两种新方法彼此912次反向查询匹配，与旧1536次版本并非完全计算匹配，不能由此单独宣称效率优势。

执行顺序

  1. 统一争议标签边界，冻结协议与失败分支。
  2. CPU核验mask、分母与随机序列。
  3. 只训练两种新版本。
  4. 保留原全32例、单步及完整路径，身份隐藏复核。
  5. 有提示信号后再做新提示词/seed确认。

旧争议图在新分析版本按同一口径对照；不拿严格新标签直接减乐观旧标签。现有开发集不升级为独立测试。

结果决定下一步

  • 验证mask独有提升且无新增损伤：初步支持选择有效，扩大确认。
  • 两种mask都提升、无可信差距：支持放松约束，尚无筛选额外价值。
  • 只增加损伤：保持约束有实际作用，检查目标和覆盖。
  • 都无改善：当前假设未获支持，检查新状态教师机会，再决定扩覆盖或停止当前实现路线。
尚未运行。

拟议开发门槛为相对旧筛选至少新增2个主要完整成功、已知损伤不增加；归因于验证选择还需优于随机mask。门槛需在运行前正式冻结，不是统计显著性标准，也不是已达到的结果。
