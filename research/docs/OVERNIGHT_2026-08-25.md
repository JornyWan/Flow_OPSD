hpsv2 −43.7σ · pickscore −32.3σ · aesthetic −22.8σ · geneval −13.4σ · ocr −7.2σ · clipscore −2.6σ

### 机制（两个诊断）

**(a) 信号幅度被砍半** — `realiz_dT_rel`（student 实际收到的目标有多远）：

| | 起点幅度 |
|---|---|
| mopd（轮转，每批单个 teacher） | **4.48%** |
| cagrad（凸组合三个 teacher） | **2.42%** |

三个方向不一致的目标做凸组合，分歧分量互相抵消。

**(b) 方向本身是错的，不只是弱** — 整体分数轨迹：

```
cagrad 跨 330 步(61→391) 只涨 +0.005，卡在 ~0.90
基线同期涨 +0.061，达到 0.9955        ← 12 倍
```

若只是幅度减半（等效降学习率），应当慢慢爬；实际是**停在坏的不动点**。

> **结论**：「对完整幅度 teacher 目标做时间平均」≠「对 teacher 目标做向量平均」。
> OPD 的轮转设计隐含依赖前者；CAGrad 换成后者，在目标非线性时是完全不同且更差的东西。
>
> 附带否证：我预测 min-norm 权重会「塌到某个 teacher」。实测 `cagrad_w_max`
> 在起点是 0.56（MGDA 原始权重 0.79，确实集中），但到 271 步已回到 0.372（≈均匀 0.33）。
> **权重退化只发生在早期，不是持续原因。**

## 6. 修掉的真 bug

| bug | 后果 |
|---|---|
| `PeftModel.from_pretrained` 缺 `is_trainable=True`（3 个 trainer 全中） | 任何从 LoRA 初始化的 run 拿到空参数列表 |
| GRPO-Guard 是 `while True` 无 epoch 上限 | BootstrapOPD 会卡在第一个微专家上耗光 72h |
| GRPO break 在 save 之前 / NFT 只存 epoch 0 | **微专家等于未训练的 student**，流水线全绿却结论全错 |
| 评测护栏 `-ne 4` 死锁 | A40 降配时无限 requeue，4 个任务各空转 6 次 |
| smoke 的 `eval_freq=10**9` 在 epoch 0 仍触发 | 每次 smoke 白付一次最贵的在线 eval |
| `if _ef:` 让 `OPD_EVAL_FREQ=0` 静默失效 | 关不掉在线 eval |
| `dict.update` 让 UNI 目录的 IR 值静默覆盖 IR 目录的 | 同一模型给出两个矛盾结论 |
