## 3. Gate A:判定 + 诊断(0043)

### 3.1 判定

**VFR = 0.9935**(2289/2304 个 state 三轴同时改善),六个 epoch 稳定在 0.9896~1.0000,无趋势。
按预注册(≥0.90):**A1 现形态在 objective 三轴内无立足点。初步判定,非判死。**

| 轴 | mean Δ | P(Δ<0) | | 轴间相关 |
|---|---:|---:|---|---:|
| clipscore | +0.07948 | 0.005 | clip–hps | +0.1726 |
| hpsv2 | +0.04532 | 0.001 | clip–pick | +0.2694 |
| pickscore | +0.07150 | 0.001 | **hps–pick** | **+0.7149** |

**相关全为正 ⇒ 三个 reward 在目标构造层面不冲突。**
这本身可写进论文:"标量求和会牺牲某一轴"的常见担忧,在 Open3 设定下不成立;
代价发生在**未进 objective 的轴**(Aes)。

### 3.2 更深的诊断:名义等权 ≠ 有效等权

| 轴 | 平均 r0 | 平均 Δ | **相对改善** |
|---|---:|---:|---:|
| clipscore | 0.2539 | +0.07948 | **+31.31%** |
| hpsv2 | 0.2829 | +0.04532 | +16.02% |
| pickscore | 0.8160 | +0.07150 | **+8.76%** |

标量和在**原始尺度**上做,而三者量纲差很多 ⇒ **clipscore 被推的力度是 pickscore 的 3.6 倍**。

把判据换成"三轴相对改善都 ≥ 各自中位数的一半",可行率从 **0.9935 掉到 0.7717** ——
**22.8% 的 state 上确实有某轴被明显冷落,只是仍为正,二值 veto 看不见。**

### 3.3 四条预注册成因的逐条对照

| 候选 | 判定 |
|---|---|
| ① veto 的轴选错了 | **强支持** |
| ② 容差取 0 不当 | **排除**(噪声主导时 P(Δ<0) 应≈0.5,实测 0.001~0.005) |
| ③ 只测了早期时点 | **未排除**,但分 epoch 无下降趋势,初步不支持 |
| ④ rank 0 采样偏差 | 部分开放(n=384/epoch 是该 rank 完整批量) |

## 5. 独立证实 RTC 的实现缺口(0046)

| 轴 | 构造增益/步 | 实现增益/步 | **实现率** |
|---|---:|---:|---:|
| clipscore | 0.07948 | 0.00083 | **1.04%** |
| hpsv2 | 0.04532 | 0.00146 | **3.22%** |
| pickscore | 0.07150 | 0.00146 | **2.04%** |
| **论文自报** | 0.03511 | 0.00046 | **1.31%** |

**我们的三个数把论文的 1.31% 夹在中间。97~99% 的构造增益在拟合阶段丢失。**

⇒ **澄清 RTC 的功过:问题陈述**正确**(现在有我们自己的证据),GN 修法**证伪**
(rtcgnfwd 全场最差,比未预条件的 rtcraw 差 −2.7σ)。**

caveat:构造增益测在 clean target,实现增益是采样图像 reward,两个总体相关但不同一,
比值**指示性**、非精确;数量级结论稳健。
