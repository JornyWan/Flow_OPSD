**预登记判据时,格划分漏掉真实可能的结局 —— 一个会话里犯了三次**(EXPERIMENT_LOG §4.368 / §4.394 / §4.414):

| 次 | 漏了什么 | 后果 |
|---|---|---|
| §4.368 | 三格都不匹配实际结局 | 只能记"判据设计失败",无格可落 |
| §4.394 | 缺"无效应"格,`≤0` 被迫兼任 | Δ=0.35×MDE 按字面落"有害"格,是过度解读 |
| §4.414 | 二选一判别("反向" vs "σ→0 独立地坏")两边都不对 | 判别失效,只能事后描述 |

**Why:** 判据一旦写下就不能改(改了就是事后另找说法),所以**漏格的代价是整条判据作废**,
而补格的成本只是多写一行。

**How to apply:**
1. **任何二选一判别,必须显式加第三格"两者皆非,逐条报"**;
2. **任何以 0 为界的格(`>0` / `≤0`),必须先切出 `|Δ| ≤ MDE` 的"无可检出效应"格**
   —— 否则噪声级的负值会被判成"有害";
3. 写完格后自检一句:**"如果实测落在 X,我能落格吗?"** 其中 X 取
   {远大于预期, 远小于预期, 恰好为零, 与预期反号但幅度很小}。

**2026-09-10 补(第五次,新的失效模式:格穷尽但**阈值太紧**)**:
§4.526 轴 A 登记了 A1「底模 gap ≤2×MDE 且训练后 ≥5×MDE ⇒ 缺陷是训练造出来的」。
实测底模 = 3.43×MDE(小但 t=+4.79 显著)、训练后 = 18.24×MDE(放大 5.3×)——
这正是最有信息量的结果,却因为 3.43 > 2 而掉进无信息的兜底格 A4,且 A4 的后果句(为另一种情况写的)完全不适用。
**How to apply:** 定阈值时先问"最可能的实际取值落在哪一格";
若某格的后果句只对一种特殊情形成立,不要把它当 catch-all。
比例型结论(如"放大 N 倍")要用**比值**定格,不要用两个绝对阈值的合取。
