**2026-08-29 一夜之内在同一个跟头上栽了四次**,四次都是"在少数几个点上读出一个看似确凿的量,
写进结论,然后被更多数据推翻":

1. `cos(g, a_geneval)` 在 n=6 时是 **−5.53 SD**(写成"几何冲突"),n=14 时变成 **+0.55 SD**,符号翻转;
2. "两约束对齐度比 reward-约束强 **45 倍**"基于 n=1 对 n=2;n=11/19 时是 **1.53 倍**;
3. 假设 H2 的 t_eff 走势 2.45 → 2.15 → 2.00 → 0.74 → **−0.88(变号)**,最终被自己的数据证伪;
4. 一阶预测的"符号一致率"做二项检验得 z=−2.85/"系统性反号",查实际序列后发现
   **累积和早期在零附近抖动,一次穿零就把大批历史点的判定整体翻掉** —— 计数统计是假象。

**Why:** 高维内积、余弦、累积量在小 n 上的取值几乎不受真实结构约束。
d≈1.9e7 维时两个**独立随机**向量的 cos ~ N(0, 1/d),SD 只有 2.3e−4 ——
"cos ≈ 0" 既可能是"真的正交",也可能是"两个向量都只是噪声",不给零模型就分不开。

**How to apply(两条都过才写进结论):**
1. **零模型对照**:给出该量在"无结构"假设下的尺度(高维余弦用 `1/sqrt(d)`),
   报告观测值是它的多少倍,而不是只报绝对值;
2. **随 n 稳定性**:同一个量至少在两三个递增的 n 上读一遍,
   **看它是否翻转/单调衰减**。随 n 单调衰减 = 早期噪声假象;
   随 n 单调增大 = 真实效应(GN 的 pick t 从 −7.1 涨到 −12.0 就是后者)。
2b. **⚠️ 不要拿"同一份数据的随机子集"冒充"随 n 稳定性"。**
   2026-08-31 实测:a1 的 veto 率趋势,随机取 50%/70% 子集 400 次,
   **斜率为负的比例都是 1.000**,看着极稳;但同一数据的置换检验 **p=0.0651 不通过**,
   且前半/后半斜率相差 6 倍。子集不是独立样本 —— 它们几乎必然复现全样本斜率的符号,
   所以"子集稳定"什么都没证明。**有判别力的是置换检验 + 前后半分裂**,
   真正的"随 n"必须是**后来新采到的数据**,不是对旧数据重采样。
3. 给每个检验统计量建**逐次记录表**(时刻 / n / 统计量),
   只在数字好看时才记录等于变相挑 n。
4. 预先写死 **n 门槛**(如 n≥20)并让分析脚本在样本不足时**拒绝打判词**,
   而不是靠自觉。

**2026-09-01 的正例(纪律第一次帮我赚到东西,而不只是拦住我)**:
Q2c 的"同 prompt vs 跨 prompt 梯度相干性",n=46 对时分析脚本按我写的
**"均值比 >3 即显著"**打出"显著更相干",比值 5.20×。补检验:t=+1.00、置换 **p=0.3796**
⇒ 纯噪声。**压住不写,继续攒**。涨到 n=140 对后:比值 7.81×、t=+3.79、
置换 **p=0.0000**、配对 t=+4.28、且按 epoch 分半(**新采的数据**)
从 +0.0031 涨到 +0.0239 —— **随 n 单调增大**,两条纪律都过,才写进结论。
⇒ 教训有二:(1) **比值不是显著性**,写判据时别拿"倍数"当门槛;
(2) 早期不显著**不等于**没效应,别急着判负,也别急着判正 —— 等新数据。
