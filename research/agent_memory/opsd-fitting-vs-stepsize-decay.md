**两族旋钮的时间演化不同**(EXPERIMENT_LOG §4.398/§4.399,2026-09-09,逐图双重差分,官方口径 A40):

```
晚期窗口 ep50→ep100:
  步长族 lr2x/lr4x/lr8x   变化 −0.0007/−0.0013/−0.0025   |t| 全 < 1.3  ⇒ 无可检出衰减
  拟合族 inner2/inner4/gacc4 变化 −0.0085/−0.0045/−0.0083  t 全显著(−2.6~−5.2)
  两族均值之比 4.71×
```

**完整图景**:步长族 ep20 达峰 → ep50 一次性回落到平台 → 之后守住;
拟合族 ep20 达峰 → **一路持续流失**到 ep100(inner2 只剩 30.5%)。

**Why:** 这意味着"某旋钮等价于 k× lr"这种换算是**阶段依赖**的
—— inner2 在外层 20 处等效 2.22× lr,在外层 100 处只等效 1.32×。

**How to apply:**
1. 任何"A 旋钮 ≈ k× lr"的换算必须标注**在哪个 ck 上算的**,不能跨阶段搬用;
2. 组合臂/剂量-反应的预登记判据,锚点必须取**与判定点同一阶段**;
3. 早停点的选择会系统性改变拟合端旋钮的排名,但基本不影响步长族排名。

注意这与 §4.298 的"一维线"不冲突:那条说的是**效应方向**共线,本条说的是**时间演化**不同。
后者反而是"拟合端不只是 lr 的重参数化"的独立证据。
