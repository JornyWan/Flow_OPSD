**2026-09-04,被 codex 0071 抓到。**

我写:qcore@dpm2-10 与 baseline@flow-40 差 **−0.0236**,可"精确分解"为

```
flow 渐近 − dpm2 渐近      = +0.0136  (57%)
dpm2 渐近 − qcore 天花板   = +0.0101  (43%)
合计 0.0237  vs 实测 0.0236  ✓
```

还据此写了"预计换 flow suffix 能拿回 57%"。

**问题:`A − B = (A − C) + (C − B)` 对任意中间点 C 恒成立。**
我选了 `C = baseline@dpm2-40`,于是"吻合"是必然的,**与机制无关**。
它没有证明 C 是因果中介,更没有证明换掉 C 那一项就能拿回那部分。

**连带的两个毛病:**
1. 我把 dpm2-40 叫"**渐近值**",但实测 dpm2 20→40 还在涨 **+0.0198** —— 没有任何证据说 40 步已收敛;
2. 我把六个离散采样设置里的最大值叫"**天花板**"。那只是单 checkpoint 的六点最大值。

**Why:** 分解式的"数值完美"来自算术,不来自数据。一旦允许自选中间点,
任何差值都能被"完美分解"成任意多项。这与
[[small-n-significance-flips]] 里"比值不是显著性"是同一类错误:
**把一个恒成立的形式关系当成了实证发现。**

**How to apply:**
1. 写分解前先问:**换一个中间点 C',这个分解还成立吗?** 若也成立,分解本身没有信息;
2. 要主张"X 项可回收",必须有**独立于该分解的**观测(如直接测 X 变化后的结果),
   不能拿分解里的一项当预测;
3. **"渐近/天花板/收敛"这类词要有证据**:至少两个更细的点显示增量趋于零。
   我这次两个词都用错了(dpm2-40 仍在涨、"天花板"只是六点最大值);
4. 陈述改成假说时要明说"**这不是因果识别**",而不是靠读者自己看出来。
