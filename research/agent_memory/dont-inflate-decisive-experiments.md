用户 2026-09-30 明确:**不要总是把实验当作"决定性的"**,而是思考**怎样对写论文有利**,
或者**从结果出发做思考/反思**即可。

**Why:** 我在一夜之内把三个臂连着标成"决定性"(`base4` §4.626"决定存亡" →
`base6mk` §4.646"决定性" → `qs7mk` §4.648"决定性"),于是每轮都在大幅改写论文定位:
"受直接威胁" → "修正措辞" → "定位稳住" → "held-out 混合"。
**那些摆动有一半是我自己造的** —— §4.646 我只有 NFE=4 与 40 两个点就下了"被更简单的基线打败"的判断,
再用完整曲线去纠正(§4.649)。把每个结果当裁决,就会被单点噪声牵着走,
也会把本该是"贡献"的发现读成"威胁"。

**How to apply:**
- 新臂登记判据**照旧**(阈值、三分法、数据前登记都不放松),但**措辞**上不写"决定存亡/决定性";
  写清"它回答哪个具体问题"即可。
- 拿到结果先问三件事:**(a) 它给论文添了哪张表/哪句话?(b) 它改变了我对机制的理解吗?
  (c) 它是否只够支撑一个更窄的陈述?** —— 而不是问"这条线还活着吗"。
- **一个竞争性基线赢了某一格,通常意味着论文该多一节对比,而不是论文没了。**
  例:"上移查询 σ 免费拿到 +12.7×MDE"本身是个干净的发现,应当写进论文当作 finding,
  而不是当成对本方法的否决。
- 与 [[dont-kill-idea-on-first-negative]] 同向:首轮为负先归因;这条再加一层 ——
  **即便归因完是真的负,也先问它能不能变成论文的一部分。**
