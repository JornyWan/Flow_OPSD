# 0060 递归诊断:每条失败的 idea,理论是否成立?能不能修好?(2026-09-01 00:45)

用户要求:"已有 idea 都得到可测结果后,思考是不是什么导致其没有 work;
如果理论上可行,recursive 地思考并 debug"。本文逐条做这件事,**只用已测数据**。

判定分三档:**理论错**(想法本身不成立)/ **层面错**(想法对、作用位置错)/
**杠杆小**(想法对、位置对,但可用幅度天生不足)。

## N1 — 静态尺度均衡权重 ⇒ **理论部分错(用了对角近似)**

| | |
|---|---|
| 立论 | 三轴相对改善不等(31.30% / 16.02% / 8.76%),按倒数加权拉平 |
| 实测 | Pick +8.4 / CLIP −7.8 / HPS −9.6(×2σ);**无权重三轴和全程低于 baseline**,ep99 −0.0170 |
| 轨迹扰动 | **2.38%**(三臂中最大,也是唯一产生显著差异的) |

**失败真因**:该做法隐含**对角假设** —— "抬高第 k 轴的权重 ⇒ 第 k 轴改善更多"。
但三轴的 reward 梯度**高度相关**(gain 相关 +0.7149),抬高某轴权重时,
被放大的是它的**特异分量**,而不是共同分量。于是策略沿 Pareto 面滑动,
在 baseline 自己的目标(等权和)上反而更差。

**理论还成立吗**:**观察成立**(三轴改善确实不等),**修法不成立**(对角近似错)。

**递归修法**:解 `G w ∝ r0`,其中 `G_jk = <∇R_j, ∇R_k>` 是**真实 Gram 矩阵**。
⚠️ **但我们从未测过 G。** §4.11 记的 `+0.7149` 是 **reward-gain 的跨 state 相关**,
**不是**梯度内积(0050 主张 B 已指出,§4.21 已确认)。Codex 0058 也明确:
测到 per-axis 梯度 norm/cosine 之前不要做 N3。

⇒ **下一步不是"再猜一组权重",而是先把 `G` 测出来。** 见 §"待办 G1"。

## A1 — 向量可行性 veto ⇒ **层面错**

| 层面 | 失败率(= 干预触发率) |
|---|---|
| **构造层(A1 实际作用处)** | **1.4%** |
| rollout 层 | 4.5% → 12.3% → **48%** |

**失败真因**:杠杆没有行程。构造层 98.6% 的目标本就三轴同升,veto **无物可否决**。

**理论还成立吗**:**成立** —— "否决会变坏的目标"没错,**错的是作用层面**。

**递归修法(已设计)**:同一逻辑搬到 rollout 层 = **A3**(`opa_cert=1`),已实现并排队。

**但 A3 也有预警**:§4.51 的 pickscore 证据显示门控会呈现"训练目标轴变差、
未优化轴变好"的**训得少签名**;§4.58 又显示 cert 的拒绝率随训练**上升**,
即它**作用最强的时段恰是增益已停止的后半程**。

**⇒ 更深一层的修法:不要"丢弃"失败样本,而要"修正"它。**
丢弃缩小有效批量(48% 拒绝 = 批量腰斩);
Codex 0058 §4.2 的**回溯步长** `α∈{1,.5,.25,.125}` 是正解 ——
把步子缩短到能通过验证为止,**样本保留、批量不变**。
这条已含在 Q-OPSD 的算法里,不必单独排臂。

## N2 — 冻结 |r| 归一化分母 ⇒ **杠杆天生小一个量级**

| | |
|---|---|
| 立论 | `L=mean(r²)/mean\|r\|` 对 r 是 1-齐次 ⇒ 梯度 0-齐次 ⇒ **对目标距离完全不敏感** |
| 验证 | 解析推导 + `torch.autograd`:baseline 在 c=1/2/4 下梯度范数**逐位相同**;N2 变 1.000/2.000/4.000× |
| 实测 | 五轴全平,实现斜率 t=+0.03,轨迹扰动 **0.51%** |

**失败真因(量化)**:N2 改变的是**逐样本相对权重**,而其可用幅度**上限就是归一化分母的离散度**。
实测批内 `cv = 0.1397` ⇒ **N2 最多改变 ±14% 的相对权重**。

    N1  改权重 3.6 倍 = ±260%   ⇒ 轨迹扰动 2.38%
    N2  改权重       ±14%      ⇒ 轨迹扰动 0.51%

**扰动幅度与权重改动幅度大致成比例。N2 的杠杆比 N1 小一个量级,而 N1 才勉强产生显著差异。**

**理论还成立吗**:**0-齐次性是事实**(双重验证),但**效应幅度受限于残差离散度,而后者很小**。

**递归修法评估**:
- 放大敏感性(如改成 2-齐次以上)⇒ 只是把一个小信号乘大,同时引入 outlier 主导风险;
- 独立旁证:旧仓库 `wf100`(另一种冻结实现、另一个奖励)**同样打平且伤了目标轴**。

⇒ **N2 属"理论对但天花板低",不值得继续投入。判定:封存,不做递归修复。**

## 待办 G1:先把 Gram 矩阵测出来(N1 的递归修复前提)

**这是唯一一条"理论可修但缺数据"的线。** 需要在锚点 `y0` 上分别取三轴梯度:

    g_k = ∇_y R_k(D(y0))      k ∈ {pick, clip, hps}
    G_jk = <g_j, g_k> / (‖g_j‖‖g_k‖)

成本:每 chunk 多 2 次 reward backward(现在只取聚合梯度 1 次)。
**测到 G 之后才能判断**:
- 若 `G` 接近对角 ⇒ N1 的对角近似本该成立,失败另有原因,需重查;
- 若 `G` 强非对角(预期如此)⇒ `G w ∝ r0` 的解会与 N1 的权重**显著不同**,
  N3 才有依据;
- 同时可算 `cos(g_k, d_Q)`,看**哪一轴**最受后缀 Jacobian 影响。

**不在 Q1 跑完前改代码**(避免动到正在运行的文件路径)。
