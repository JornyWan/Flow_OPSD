# 0049 预注册:N2 = 冻结拟合损失的 |r| 归一化分母(2026-08-31 09:55,launch 前写定)

**这是第一个"步长类"干预。A1(veto)与 N1(权重)都是"方向类",
而 §4.12/本文 §② 证明方向类干预受结构性上限约束。**

## ① 假设

DiffusionOPSD 丢掉 97~99% 构造增益(0046),不是因为目标构造得不好,
而是因为**拟合损失在数学上看不见"目标有多远"**。冻住归一化分母可恢复该敏感性,
从而抬高实现率 G_realized / G_construct。

## ② 机制(解析 + 数值双重验证,launch 前完成)

`train_opsd_ri_sd3.py:1606-1611` 的损失:

    wf_p     = |y_pos − y_plus|.mean(dim=rd, keepdim=True).clip(1e-5)   # = mean|r|,逐样本
    pos_loss = (accp * (y_pos − y_plus)**2 / wf_p).mean(dim=rd)         # = mean(r²)/mean|r|

令 A=mean(r²), B=mean|r|, L=A/B:

    ∂L/∂r = (1/n)[ 2r/B − A·sign(r)/B² ]
    r → c·r  ⇒  A→c²A, B→cB
    ∂L/∂r|_{cr} = (1/n)[ 2cr/(cB) − c²A·sign(r)/(c²B²) ] = (1/n)[ 2r/B − A·sign(r)/B² ]

**完全相同 —— L 是 1-齐次、梯度 0-齐次。把目标推远 c 倍,梯度一个字节都不变。**

数值验证(`torch.autograd`,c ∈ {1,2,4}):

| | c=1 | c=2 | c=4 | c=4/c=1 |
|---|---:|---:|---:|---:|
| baseline | 0.091297 | 0.091297 | 0.091297 | **1.000×** |
| N2 冻结 | 0.091537 | 0.183073 | 0.366147 | **4.000×** |

c=1 处两者只差 0.3% ⇒ **有效学习率与 baseline 可比,只改敏感性、不改尺度。**

经验旁证(§4.12):reward 权重相差 3.6 倍的三条臂,`opa_delta_res` 只差 0.2%。

## ③ 改动(最小、默认关闭)

`RPI_N2=1` 时,把逐样本瞬时 `wf_p/wf_n` 换成**全局 EMA 标量**(动量 `RPI_N2_MOM=0.99`,
跨 rank `all_reduce(AVG)` 保证各 rank 一致)。损失变 2-齐次、梯度变 1-齐次。
EMA 保住平均尺度。`RPI_N2` 未设时代码路径与 baseline **逐字节相同**。

**不改的东西**(与 baseline / A1 / N1 严格一致):数据(train.txt 25415 / test.txt 1000,
md5 已校)、config `sd35_open3`(1:1:1, β=0.1)、base 模型、100 updates、
`RPI_SEED=20260830`、trust region rho、advantage 归一化、评测脚本与 prompt 集。

## ④ 主判据(预注册,先写后测)

**主**:训练侧实现增益。取 update 20–100 的 `reward_avg` 线性斜率(排除 0046 §② 记录的
前 6 epoch 暂态),与 baseline 同区间配对比较。
构造侧 N2 不改动 ⇒ 斜率之比即实现率之比。

> **两条使用限制(2026-08-31 10:40 实测补充,N2 出结果前写定):**
>
> **(i) 该指标只能用于权重相同的臂。** `reward_avg` 是**加权和**,
> N1 的权重是 1:1.954:3.573,其 `reward_avg` 起点 **3.3315**,baseline 是 **1.2039** ——
> 量纲根本不同,跨权重比斜率无意义。**N1 不适用此判据**(其判负依据是 held-out 五轴)。
> N2 权重仍是 1:1:1,**适用**。
>
> **(ii) 必须在公共 step 集上比,不能各自取"20–100"。** 实测这个坑很大:
> a1 中途只有 85 个点,若各自按"20–100"取窗,得 baseline 1.084e−3 / a1 1.315e−3,
> Δ=+2.31e−4 看着接近显著;改用公共集(20–84, n=65)后
> baseline 1.3025e−3 / a1 1.3148e−3,**Δ=+1.23e−5, t=+0.07,彻底打平** ——
> **错配窗口把差异放大了约 19 倍。**

> **⚠️ 检出力补记(2026-08-31 14:00,N2 未出结果前):该主判据是低检出力指标。**
> 实测两臂斜率差的 SE_Δ ⇒ **最小可检出差异 = baseline 斜率的 32%**
> (n2 中途 20–52 与 a1 完整 20–100 都恰好是 32%)。
> ⇒ 打平时**只能断言"实现斜率未改变超过 32%",不能断言"毫无改变"**。
> 我们攻击的是 98.7% 的缺口,而该指标只看得见一次性堵掉约 1/3 缺口的干预。
> **因此判定以 held-out 五轴为主(retest σ 极小,检出力高),实现斜率作机制佐证并附 MDE。**

**次**:held-out 三轴 @ck100,判显著沿用既定门槛 **|diff| > 2σ 且 |t| > 2.5**
(retest σ:pick 0.00075 / clip 0.00108 / hps 0.00043)。

**反向操纵对照**:aesthetic / imagereward 两轴**不在 Open3 目标里**。
若三轴涨而这两轴显著跌 ⇒ 是 reward hacking,不算正向结果。

> **修订(2026-08-31 10:20,N2 出结果前):aesthetic 不是干净对照。**
> N1 全表显示 aes 动了 **+10.08×2σ(t=+10.43)—— 是全部五轴里最大的效应**,
> 而它根本不在目标里。它显然与 pickscore 同向共动。
> ⇒ **只有 imagereward 是干净对照**(N1 下 t=−1.18,其余四轴全动它不动)。
> 判 N2 是否 reward hacking **以 imagereward 为准**,aes 仅作参考。

## ⑤ "N2 等于没改"的自检(避免重蹈 A1 覆辙)

A1 打平的真因是 veto 几乎从不触发(可行率 0.9865)。N2 的同类风险:
若归一化分母本来就几乎是常数,冻不冻结没区别。

因此逐 step 记录 `n2_wf_cv_{p,n}`(批内跨样本变异系数)与 `n2_wf_drift_{p,n}`(瞬时/EMA)。

> **若 median(cv) < 0.05 且 |median(drift) − 1| < 0.05,则 N2 数值上 ≈ baseline,
> 打平结果不可解释为"机制无效",只能说"该杠杆在此设置下没有行程"。**

## ⑥ 预写失败模式(先写,防止事后找补)

- **(a) 无行程**:cv≈0 ⇒ 见 §⑤,判"未真正施加干预",需换更大杠杆(如直接放大 rho)。
- **(b) 不稳定**:2-齐次损失让大残差样本主导 ⇒ grad_norm / total_loss 发散或 reward 崩。
  证据:`total_loss` 或 `reward_avg` 相对 baseline 出现非单调劣化。
  补救方向(**不在本次改**):逐样本残差裁剪,或把 EMA 动量调小。
- **(c) 实现率涨但 held-out 不涨**:把 reward 代理追得更紧 = 过拟合代理。
  由 §④ 的 aes/imgR 对照识别。
- **(d) 两者都涨**:正向结果。此时才考虑跑满 300 updates 与论文 Open3 数值对齐。

## ⑦ 与 A2 的取舍(为什么先跑 N2)

A2(post-fit commit gate)也是步长类,但它是**稀有门**:0046 实测 G_realized 平均为正,
门几乎不会触发 ⇒ 结构上重复 A1 刚演示过的失败模式。
N2 是**逐步生效**的机制,不依赖罕见事件。故先 N2。
