## ② 为什么这个负结果比 A1 的更有价值

| | A1 | **N2** |
|---|---|---|
| 干预是否真正施加 | **否** —— veto 仅 1.39% 步触发 | **是** —— 每步生效,`cv≈0.136` |
| 有效学习率是否可比 | (不适用) | **是** —— `opa_pos_loss` 比值 **0.989** |
| 打平说明什么 | 只说明**干预没发生** | **说明假设本身不成立** |

**N2 精确移除了拟合梯度的 0-齐次性**(解析 + `torch.autograd` 双重验证,§4.13:
baseline 在 c=1/2/4 时梯度范数逐位相同,N2 变 1.000/2.000/4.000×),
**结果什么都没改变。**

⇒ **"实现缺口源于拟合阶段对目标距离不敏感"这一假设,被否定。**
这是 0049 §⑤ 事先设计要能区分的情形,现已区分成功。

**诚实边界(§4.31)**:实现斜率的最小可检出差异是 baseline 的 **32%**,
故只能断言"未改变超过 32%",不能断言"毫无改变"。held-out 五轴的检出力高得多,
且五轴同时打平,结论稳健。

## ③ 与 0055 的关系:三条臂的失败被统一解释

0055 确立:构造目标的 **rollout 可达率**内在地随训练下降
(98.73% → 95.49% → 87.67%,100 updates 时 52%)。

| 臂 | 干预维度 | 为何撼不动 |
|---|---|---|
| N1 | 目标**方向** | 换方向不改变"够不着" ⇒ 沿 Pareto 滑动(保持率 87.9%→75.6%) |
| A1 | 目标**筛选** | 构造层 98.6% 都可行,veto 无物可否决 |
| **N2** | 拟合**步长敏感性** | **把够不着的目标追得更用力,依然够不着** |

**三条臂都在优化一个模型到不了的目标。**

## ④ 一个被**推翻**的自家假设:Aes 不是稳定的"敏感度探针"

§4.26 曾提出待验假设:Aes 在臂间对比里系统性地是效应最大轴(当时 2 条独立臂,P=0.04)。
在 ck100 正式计数:

    N1  最大轴 = aesthetic (+10.08)   ← 真实效应
    A1  最大轴 = clipscore (+0.37)    ← 但五轴全 ≤0.37,"最大"是噪声
    N2  最大轴 = aesthetic (+1.34)

**命中 2/3,P 仍是 0.04,未升格。** 更根本的是:A1 与 N2 的五轴效应都接近零,
**"哪一轴最大"这个统计量在它们身上没有判别力** —— 该假设是欠定的,不是被支持的。
(中途曾据 ck50 读数以为可升格,是抢跑;用预注册的 ck100 正式计数才发现不成立。)

**保留的结论**:ImgR 在四条臂里始终最不动,作为 reward-hacking 的干净对照仍然成立。
