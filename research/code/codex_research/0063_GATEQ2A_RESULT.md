# 0063 ★★★ Gate Q2a:逐样本 LoRA 梯度**无净对齐** —— 这解释了整个项目的空结果(2026-09-01 02:25)

## ① 结果(中途 n=495 对,B=6/记录,3 updates)

| | canonical 目标 | Q 目标 |
|---|---:|---:|
| 两两余弦 中位 | +0.00046 | +0.00029 |
| 两两余弦 **均值 ρ** | **+0.00097** | **−0.00069** |
| 两两余弦 sd | 0.03220 | 0.02746 |
| 负余弦比例 | 49.2% | 51.7% |

**LoRA 可训练参数 d = 18,776,064 ⇒ 零模型 `sd = 1/√d = 2.31e−04`。**

## ② 两个必须分开的读法

**(a) 离散度 = 零模型的 140×** ⇒ **梯度之间有真实结构**,不是纯随机向量
(单个对的 |cos| 可达 0.1)。

**(b) 但均值 ρ ≈ 0.001 ≈ 0** ⇒ **没有净对齐**。而决定抵消程度的是**均值**,不是离散度:

    ‖批平均‖² = 1/B + (1−1/B)·ρ

| B=6 | 批平均梯度范数 |
|---|---:|
| canonical(ρ=+0.00097) | **0.4092** |
| Q 目标(ρ=−0.00069) | 0.4075 |
| **纯随机(ρ=0)** | **0.4082** |
| 完全对齐(ρ=1) | 1.0000 |

**三者几乎相同(差 0.24%)。批平均后与"平均一堆随机向量"无法区分。**
渐近(B→∞)相干分量只占单样本梯度范数的 **√ρ ≈ 3%**。

## ③ 这正是预写的失败模式 (a)

0062 §④ 写定:
> **Q2a-2 不成立**(Q 目标的梯度并不更相容)⇒ 说明第二段损失来自**跨样本梯度抵消**,
> 与目标质量无关。**此时改目标构造是徒劳的**,应转向 gradient-coherent batching / adapter experts。

**Q2a-2 实测不成立**(Q 的 ρ 甚至略低于 canonical)。

## ④ 它解释了整个项目的空结果

| 臂 | 改的是什么 | 为何无效 |
|---|---|---|
| N1 | reward 权重 | 改的是**目标** ⇒ 只影响单样本梯度方向 |
| A1 | 目标筛选 | 同上 |
| N2 | 拟合损失几何 | 同上 |
| **Q-OPSD** | **上升方向(+72% 更好的目标)** | **同上** |

**目标决定每个样本梯度的方向;而它们平均后互相抵消。改善单个方向,改善不了平均值。**

这与 §4.47 的两段分解吻合:②→③(参数实现)丢 76~100% ——
**现在那一段的损失机制有了名字:跨样本梯度抵消。**

⇒ **Q1b 的 +72% 更好目标,很可能同样兑现不了。**
这正是把 Gate Q2 挡在训练臂之前的意义。

## ④b ⚠️ 自我修正:§④ 的因果说过头了

§④ 写的是"梯度平均后互相抵消 ⇒ 解释了整个项目的空结果"。**反证**:
baseline 的 reward 确实从 1.2039 涨到 1.5987 —— **训练是有效的**。
若真"抵消到无效",baseline 不会学到东西。

**更准确**:相干分量虽只占 **√ρ≈3%**,但**那 3% 足以驱动学习**。
真正的问题是:**改善目标提升的是单样本梯度的方向,而实测这并不提升 ρ**
(Q 的 ρ 甚至略低于 canonical)⇒ **批平均的相干部分对目标质量不敏感。**

## ④c 处方第 1 条已被数据削弱:随机微批间无相干性差异

批间 ρ 的 sd 实测 **0.00815** vs 零模型 **0.00778**,**比值 1.05** ⇒ 无天然相干子群。
(功率限制:每批 6 样本抽自 48 prompt,**稀有**相干簇难被整批命中,故只能排除**普遍性**结构。)

> **⚠️ 2026-09-01 补记(Q2c,见 EXPERIMENT_LOG §4.81):上面这句"功率限制"说中了。**
> 随机分组下只有约 2% 的样本对同 prompt,同 prompt 子群在该设计下**不可见**。
> Q2c 改为**优先挑同 prompt 对**后测出:同 prompt 平均余弦 **+0.01300** vs
> 跨 prompt **+0.00166**,**7.81×**;置换检验 p=0.0000、配对 t=+4.28、
> 随新采数据单调增大(epoch0–2 +0.0031 → epoch3–5 +0.0239)。
> **本节结论("无天然相干子群")仅对随机分组成立,不适用于按 prompt 分组** —— 无需修订,
> 但引用时必须连同这条补记。
> 另注:该相干子群**不可通过分批利用** —— 梯度累积是线性的,整批梯度与 microbatch
> 如何切分无关,按 prompt 分组是恒等变换(§4.81)。可用的是**批构成**(prompt 数 × 每 prompt 图数),
> 且同算力重组的天花板仅 60.3%→65.7%。

## ⑤ Caveat(不可略)

1. **n=495 对,来自 21 条记录、每条 6 样本,仅 3 updates** —— 中途读数,跑完再定稿;
2. 测的是**微批内**(B=6)的逐样本梯度。真实更新累积 **48 微批 × 3 rank**,
   **有效 B 大得多 ⇒ 抵消只会更严重**,不会更轻;
3. 仅在训练**早期**(3 updates)测得。相容性是否随训练变化,需要更长的探针;
4. ρ 虽 ≈0 但**为正**(canonical +0.00097)⇒ 存在极弱的净对齐,不是严格 0。

## ⑥ 由此得出的方向转向(按 0062 §④ 预写的处方)

**不再优化目标。** 下一步应测/做的是:

1. **相干性从何而来**:把 ρ 按 prompt 相似度、`R_old` 分层、时间步分组,
   看是否存在**天然相干的子群** ⇒ 若有,`gradient-coherent batching` 可行;
2. **adapter experts**:若不同子群的梯度天然冲突,共享单个 LoRA 就是错的容器;
3. **AdamW 预条件**:测 `cos(g, AdamW(g))` —— 二阶矩归一化可能进一步旋转方向。

**注意**:这三条都**不是**目标构造问题。**本项目此前 6 个 idea 全在目标侧,
现在有实测依据说明瓶颈不在那里。**
