## ① 命题

RTC 主线攻击的问题是**实现率只有 1~3%**(0046,我们自己的独立测量,
把论文自报的 1.31% 夹在中间)。GN 预条件那个**修法**已证伪(§4.4),
但**问题为什么存在,一直没有定量解释**。

**本文的解释**:构造增益是**逐样本**量,而一次更新只能沿**批平均**方向走。
样本 i 拿到的增益 ∝ `g_i·ĝ` 而非 `‖g_i‖`,于是

```
实现率 ≈ E[g_i·ĝ]/E‖g_i‖ = ‖G‖²/(‖ḡ‖·E‖g‖)
```

`Gate B` 探针**直接测得** `‖G‖²=ḡ_A·ḡ_B` 与 `‖ḡ‖²=‖ḡ_full‖²`,
且 `E‖g‖²=‖G‖²(1+B_noise)`,故

```
预测实现率 = sqrt(dot_ab/nrm_full2) / sqrt(1 + B_noise)
```

**已加进 `gateB_analyze.py`,每次更新自动产出。无额外算力。**

## ③ 有判别力的版本:逐轴排序(**设计,今夜不实现**)

**可证伪预测:clipscore 的逐样本梯度相干性三轴最低。**
若成立,就把 §4.5 那句"clipscore 的构造目标大量落在模型不可达的方向上"
从**猜测**变成**可操作的定义**:"不可达" = "逐样本方向互不相容、批平均后相互抵消"。

**测法(需新代码)**:0046 的两个量来自**同一次 open3 运行**,
故必须在 open3 内做**逐轴**分解 —— 对每个轴 a 单独构造 `y_a^+ = y0 + budget·normalize(∇_y R_a)`,
再取逐样本 LoRA 梯度求两两余弦。成本 ≈ Q2a 探针的 3 倍。
**不可用 reward-specific config 代替**:那些臂 β=1.0 而 open3 是 β=0.1,口径不同。

**零模型(必须做)**:n=3 个轴,随机排列命中正确顺序的先验概率 **1/6 = 16.7%**。
⇒ **单次命中不构成证据**。判据须为:
(a) 三轴 `ρ_cross` 的**两两差**各自过 `|t|>2.5`(不是只看排名);
(b) 且 clipscore 与 hpsv2 的差过置换检验 p<0.05。
只满足排名而差值不显著 ⇒ **判为无结论**,不是"支持"。

## ⑤ 两处更正(**写于 bnoisep n=2、判决未落地之前**)

### (a) 我自己的判据有洞:(6.0%, 8.0%] 未定义

§② 写的是:R-a 通过区间 **[0.5%, 6.0%]**、R-c 证伪 **>8%**。
**中间的 (6.0%, 8.0%] 没有定义**,而当前读数(6.88%)恰好落在那里。
这是判据本身的疏漏,**必须在判决落地前补,不许事后挑解释**。

**补充判据(现在写死)**:中位数落在 **(6.0%, 8.0%]** ⇒ 判为 **"未决"**
—— 既不算"解释成立",也不算"证伪"。理由:该区间对应"理论高估约 2~3 倍",
既不能说相干性解释了缺口,也不能说它与缺口无关。

### (b) 余弦法与半批法差 2~4 倍 —— 应以半批法为准,§4.84 的 2.77% 偏低

同一物理量,两个估计量不一致:

| | 信号占比 | `B_noise` | 预测实现率 |
|---|---|---|---|
| 余弦法(Q2a/Q2c 的 ρ) | 56.0% | **729** | 2.77% |
| **半批法(按 prompt,ep0)** | **86.4%** | **181** | **6.88%** |

**原因是两者测的根本不是同一个泛函:**
```
ρ = E[cos(g_i,g_j)] = ‖E[ĝ]‖²          ĝ = g/‖g‖  ← 归一化后再平均
半批法 = ‖E[g]‖² = ‖G‖²                            ← 直接平均
```
`‖ḡ‖²/E‖g‖² = 1/B + (1−1/B)ρ` 这个把二者连起来的式子
**要求各样本梯度范数相同**。范数不齐时二者可任意偏离:
若**范数大的样本更对齐 G**(高 reward 梯度的样本更有信息量,先验上合理),
`‖E[g]‖²` 会显著大于 `E‖g‖²·‖E[ĝ]‖²`。实测方向与此一致。

**⇒ 判定:以半批法为准。** 两条理由:
1. 假设更少(不需范数齐次),且已用**合成已知答案**验证 ±2%(0064 §⑥);
2. **实现率公式里出现的正是 `‖G‖²` 与 `E‖g‖`,不是 ρ** ——
   `ḡ` 才是优化器实际走的方向。用 ρ 是一步近似,现已知该近似在此处不成立。

**⇒ §4.84 用余弦 ρ 得到的 2.77% 是偏低的估计,应改用 6~7%。**
而 §4.4 实测实现率是 **1.04~3.22%**,故:

> **理论高估 2~6 倍。相干性只解释了实现缺口的一部分,不是全部。**

上一轮把 "2.77% 落在实测区间内" 当作正面证据 —— 那是用了**有偏的估计量**,
现予更正。此处不再是"数量级吻合",而是"**同数量级但系统性高估**"。

**还有一处让高估更严重**:公式分母用 `E‖g‖`,而半批法只给 `E‖g‖²`;
由 Jensen `E‖g‖ ≤ sqrt(E‖g‖²)`,代入 sqrt 值会**低估**预测实现率
⇒ 真实预测值 **≥ 6.88%**,高估只会更大。

**剩余缺口的候选解释(尚未检验,不排序)**:
(i) AdamW 预条件改变了实际走的方向(§4.79 实测其把梯度摊开 7~12 倍);
(ii) 构造增益测在 clean target、实现增益是采样图像(0046 §③ 自己的 caveat);
(iii) 一阶线性响应假设在 100 updates 的尺度上不成立。
