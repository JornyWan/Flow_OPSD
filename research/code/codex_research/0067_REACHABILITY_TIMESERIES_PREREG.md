**状态:预注册。设计与判据写于任何数据之前。2026-09-01。**
上游:0046(实现率 1~3% 且随训练 12× 衰减)、0066(Gate B 判决)、EXPERIMENT_LOG §4.87c/§4.91。

## ① 剩下的唯一未解释项

0066 关掉了两条大方向(target-side / batch-side),并把实现率的**长程水平**解释到了
2.87%(与 hpsv2 的 3.22% 相容)。**但时间结构没解释掉**:

| | 实测(0046) | 相干性理论(0066) |
|---|---|---|
| 衰减幅度 | **约 12×**(前 6 epoch → 全程 100 upd) | **1.47×**(25 epoch 内) |

⇒ 主因在别处。最自然的候选就是 **RTC 的原始命题**:
**构造出的目标越来越落在模型不可达的方向上。**
GN 预条件那个**修法**已证伪(§4.4:`rtcgnfwd_781=0.7503` 全场最差,−2.7σ),
但**问题陈述从未被当作时间序列检验过**。

## ② 要测的量

设 `y_θ` = 模型在查询态处输出的 x0,`J = ∂y_θ/∂θ`(只对 LoRA 参数),
`g = ∇_y R` = reward 上升方向(**目标构造已经在算它**)。

```
可达分数  ρ_reach ≡ cos(g, J Jᵀ g)
```

一阶意义下,沿 `θ ← θ + η Jᵀg` 走一步,`y` 的位移是 `η J Jᵀ g`,
其带来的 reward 增益与"把 y 直接沿 g 移动同样长度"之比正是 `cos(g, JJᵀg)`。
⇒ **`ρ_reach` 就是"这一步最多能实现构造增益的百分之几"的一阶上界。**

**这正是 cron 提示里的 `rtc_cos_gn_g`**,而提示里的 `rtc_rand` 臂正是下面 C-c 的零模型。
**原 RTC 的仪器设计是对的,只是从未按 epoch 画成时间序列。**

**算法(每次更新对 `_ns` 个样本各做一次)**:
1. `v = Jᵀg` —— 一次反传:`torch.autograd.grad((y_θ * g).sum(), lora_params)`;
2. `Jv` —— **有限差分 JVP**:`θ ← θ + ε·v/‖v‖` 后再前向一次,`Jv ≈ (y_θ' − y_θ)/ε`,
   随后**精确还原** `θ`(在 `torch.no_grad()` 下保存/恢复 `p.data`);
3. `ρ_reach = cos(g, Jv)`。

成本 ≈ 每样本 1 次额外反传 + 1 次额外前向,与 Q2a 探针同量级。
**不改训练**(只读梯度、扰动后立即还原)。

## ③ 判据(**先写后测**)

- **C-a 趋势**:`ρ_reach` 对 epoch 走三判据 —— 置换 **p<0.05** **且** 前后半斜率同号
  **且** 幅度比 <3。(与 §4.88/§4.91 同一套,不另立标准。)
- **C-b 幅度**:实测实现率衰减约 12×。记 `ρ_reach` 首末比为 `D`:
  - `D ≥ 3` ⇒ 可达性收缩是**主要**成因;
  - `1.5 ≤ D < 3` ⇒ **部分**成因,需与相干性(1.47×)合并解释;
  - `D < 1.5` ⇒ **不是**成因,判负。
- **C-c 零模型(关键)**:同时测 `ρ_rand = cos(u, J Jᵀ u)`,`u` 为与 `g` 同维的随机单位向量。
  - 若 `ρ_rand` **同幅度下降** ⇒ 下降来自 **J 本身在收缩**(LoRA 表达力/秩塌缩),
    **与"目标变得不可达"无关**;
  - 只有 `ρ_reach` 的下降**显著快于** `ρ_rand`(两者比值的趋势亦过 C-a 三判据)
    才支持 RTC 的命题。**单看 `ρ_reach` 下降不算数。**
- **C-d 精度**:n_updates ≥ 25;不足则**拒绝打判词**。
- **C-e 有限差分健全性**:`ε` 取两个值(1e-3、1e-4),`ρ_reach` 相对差需 <10%;
  否则说明有限差分不稳,结果作废(不得只报好看的那个 ε)。

## ④ 预写失败模式(出现即照此解读)

- **(a) C-a 不过(无趋势)**:可达性不是成因 ⇒ 12× 的时间结构**三个候选全部落空**
  (相干性只给 1.47×、可达性无趋势、batch 已判负),必须提出**第四个**假设,
  且不得回头调已判负的臂。
- **(b) C-a 过但 C-c 不过**(`ρ_rand` 同步下降):问题在 **J 收缩**,不在目标构造。
  这会把主线从"怎么造目标"整个换成"**为什么 LoRA 的可达子空间在训练中塌缩**",
  与 §4.79 实测的 `k_eff` 从 ~1300 降到 ~600 直接对上 —— 届时应优先查两者是否同一现象。
- **(c) C-a 过且 C-c 过且 C-b 给 D≥3**:**RTC 的问题陈述在时间版本上被证实**。
  届时仍须解释:为什么 GN 预条件(直接朝可达子空间投影)反而**最差**(§4.4)。
  一个可检验的猜想是 GN 方向虽可达但**范数极小**,单步增益的"不小于"保证
  被信赖域裁剪(rho=0.10)吃掉 —— 该猜想须另行预注册,不在本门内下结论。

## ⑦ 【设计修订,2026-09-01】改用**只需 VJP** 的构造 —— 原设计在 fp16 下会产出垃圾

落地前先做 §⑥ 前置条件 #2(玩具模型已知答案验证),**当场否掉了原设计**。

### (a) 原设计(有限差分 JVP)在 fp16 下失效

`Jv ≈ (y_θ(θ+εv) − y_θ(θ))/ε`,在玩具模型上实测:

| ε | fp32 相对误差 | **fp16 相对误差** |
|---|---|---|
| 1e-2 | 0.00% | 7.14% |
| 1e-3 | 0.00% | **68.87%** |
| 1e-4 | 0.08% | **101.43%**(cos 变号) |

训练是 `mixed_precision="fp16"`,而 fp16 只有约 3 位十进制有效数字,
小 ε 下 `y1−y0` 完全被舍入噪声淹没。
**若照原设计实现,会得到一条看似正常、实为噪声的时间序列。**
(C-e 判据本可事后抓到,但要浪费一整次运行。)

### (b) 修订设计:`ratio = R(g) / E_u[R(u)]`,`R(d) ≡ ‖Jᵀd‖²/‖d‖²`

`R(d)` 是 `JJᵀ` 在方向 `d` 上的 **Rayleigh 商** —— **一次反传即得**
(`torch.autograd.grad((y_θ·d).sum(), lora_params)` 再取平方和),
**不需要 JVP、不需要扰动参数、不需要有限差分**。

玩具模型验证(奇异值谱跨 3 个数量级):

| `g` 的构造 | `ratio` |
|---|---|
| 随机方向(零模型) | 1.37 |
| top-10 奇异方向内 | **15.88** |
| bottom-50 奇异方向内 | 0.000 |
| `J` 的零空间(完全不可达) | 0.000 |

**fp16 稳定性:相对误差 0.001%**(`‖Jᵀd‖²` 无相消,与有限差分的 69~101% 形成对比)。

### (c) 三个额外好处

1. **C-c 零模型内建进统计量**:`J` 整体收缩(如 §4.79 的 `k_eff` 1300→600)会让分子分母**同步**变化,
   `ratio` 不变;**只有 `g` 特异地移向不可达方向,`ratio` 才下降**。
   ⇒ 原 §③ C-c 需要的"另测 `ρ_rand` 再比趋势"现在是**同一个数的分母**,不会口径错配。
2. **§⑥ 的前置条件 #1(扰动 LoRA 参数后精确还原)整条取消** —— 风险最高的一环没有了。
3. 仍同时记录 `R(g)` 与 `E_u[R(u)]` 两个分量:后者的走势可直接与 §4.79 的 `k_eff` 衰减对照,
   看"J 收缩"与"子空间维数下降"是不是同一现象。

### (d) 判据的对应修改

- **C-a / C-b / C-d 不变**,统计量由 `ρ_reach` 换为 **`ratio`**;
  C-b 的幅度阈值同样用首末比 `D`(≥3 主要成因 / 1.5~3 部分 / <1.5 判负)。
- **C-c 改为**:分别对 `R(g)` 与 `E_u[R(u)]` 各做一次趋势检验。
  - 若两者同步下降而 `ratio` 平 ⇒ 是 **J 整体收缩**,不是"目标不可达"(⇒ 0067 §④(b));
  - 若 `ratio` 显著下降 ⇒ 支持 RTC 命题(⇒ §④(c))。
- **C-e 改为**:随机方向数 `K ≥ 8`(玩具中单次随机抽样给 1.37 而非 1.0,K 太小分母会抖);
  并报告 `E_u[R(u)]` 的 K 内标准误,要求 SE/均值 < 20%。
  (原 C-e 的"两个 ε 相对差<10%"随有限差分一并作废。)

### (e) 成本

每个被探样本 `1 + K` 次反传(K=8 ⇒ 9 次),与 Q2a 探针(6 次)同量级。
仍是**只读**探针,不进 loss、不改 `.grad`、不动参数。

## ⑨ 【零模型加强,写于 n=4、判决之前】各向同性高斯**太弱**

首批 4 条记录(epoch 0 为初始化瞬态):`ratio = 0.945, 0.094, 0.132, 0.320`
—— 去掉 epoch 0 后**全部远小于 1**,即 reward 方向比随机方向难达 3~10 倍。

**但这可能不是 reward 特有的。** `g = ∇_y R(y0)` 是 reward 模型给出的
**结构化、空间光滑**的图像空间梯度;而 `u ~ N(0,I)` 是**白噪声(高频)**。
若扩散模型的 Jacobian 对高频方向增益更大,则**任何光滑方向**都会得到 ratio ≪ 1,
**与 reward 无关**。⇒ 现有零模型分不开"reward 特异性"与"光滑性"。

**加强(现在写死,先于任何判决)**:再记一个 `R(g_perm)`,
`g_perm` = 把 `g` 沿 **batch 维**做循环移位(样本 i 拿到样本 i+1 的 reward 梯度)。
- **保留** g 的空间频谱、范数尺度、以及"是一个真实 reward 梯度"这一切属性;
- **破坏** 的只有"这个 g 对应这个样本"的配对关系。

**修订判据:**
- 主统计量改为 **`ratio_perm = R(g) / R(g_perm)`**;
  `ratio_iso = R(g)/E_u[R(u)]` 降为辅助量(仍记录,用于看 J 的整体各向异性)。
- **C-b 幅度**判据改用 `ratio_perm` 的首末比。
- **新增 C-f(区分性)**:若 `ratio_perm ≈ 1`(95%CI 含 1)而 `ratio_iso ≪ 1`,
  则结论是"**光滑方向难达,与 reward 无关**" ⇒ **RTC 命题不被支持**,
  真正的现象是 J 的频谱偏好,应转向"为什么扩散模型的可达子空间偏高频"。
- 若 `ratio_perm` 显著 <1 **且**随训练下降 ⇒ 才是 RTC 命题的证据。

**代价**:每周期多 1 次 VJP(共 `2+K` 次)。
**已取消当前作业 1038474(仅跑了 15 分钟、4 条记录)并按加强版重投** ——
零模型不够强的结果无法判读,15 分钟比一个不可解读的两小时结果便宜。

## ⑩ 【判决前补记】`ratio_perm < 1` 有**两种读法**,现有统计量分不开

首批数据(n=4,加强零模型版):
```
ep         :   0       1       2       3
ratio_iso  : 0.950   0.148   0.374   0.107
ratio_perm : 1.117   0.241   0.503   0.090
```
`ratio_perm < 1` 意味着 `‖Σᵢ Jᵢᵀgᵢ‖² < ‖Σᵢ Jᵢᵀg_{i+1}‖²`。**两种机制都能产生它:**

- **(A) 逐样本衰减**:`‖Jᵢᵀgᵢ‖ < ‖Jᵢᵀg_j‖`,即**模型在样本 i 处的 Jacobian
  恰好在"能改善样本 i 自己 reward"的方向上最小**。⇒ 这是 RTC 命题的**尖锐版本**。
- **(B) 跨样本抵消**:逐项范数相当,但**正确配对的项彼此抵消得比随机配对更厉害**。
  ⇒ 这是"冲突"的加强版(比 Q2a 的"近乎正交 ρ≈0.0015"更强)。

**两者的干预含义完全相反**:
(A) ⇒ 要改**目标构造**(把 g 投到可达子空间,即原 RTC 的思路);
(B) ⇒ 要改**样本聚合**(冲突消解 / 分组更新),目标构造再准也没用。

**现有统计量只看"和的范数",分不开。**(此前四条伪影排查 —— 分母恒等、
与符号无关、batch 对齐、roll 不跨 rank —— 只说明观测本身可信,不解决归因。)

### 判别设计(**先写后测**,本轮不实施)

在**单样本**上重算:`R₁(i) = ‖Jᵢᵀ gᵢ‖²/‖gᵢ‖²` 与 `R₁ᵖ(i) = ‖Jᵢᵀ g_{i+1}‖²/‖g_{i+1}‖²`
(把 `y_pos` 只在样本 i 上取和即可,无需改别处)。
- 若 `R₁/R₁ᵖ ≈ ratio_perm`(都 ≪1)⇒ **机制 (A)**,逐样本衰减;
- 若 `R₁/R₁ᵖ ≈ 1` 而整批 `ratio_perm ≪ 1` ⇒ **机制 (B)**,跨样本抵消。
成本:每周期 2 次额外 VJP(只取 1~2 个样本)。
