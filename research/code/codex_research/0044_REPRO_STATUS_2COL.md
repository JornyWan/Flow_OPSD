## ④ 尚存的候选解释

1. **world_size 3 vs 论文 8 policy ranks**(README L323 明写 8)。

   已派 ck50 评测(job 1037174)取该斜率。
3. **CLIP 梯度信号本身更弱/更噪** —— 目前无直接证据,列出备查。

## ⑥ 后续诊断(2026-08-30 19:00~20:00)

### 6.1 "预算不足"被**削弱**

clipscore 臂的 held-out CLIP:

| | CLIP |
|---|---:|
| base | 0.2408 |
| ck50 | 0.3105 |
| ck100 | 0.3186 |

| 区间 | 斜率 /update |
|---|---:|
| ck0 → ck50 | +0.001394 |
| ck50 → ck100 | **+0.000161**(减速到 **12%**) |

按后段斜率线性外推,补到 0.340 需再 133 updates(总计 233)。
**但曲线已明显饱和,线性外推不可靠** —— 更可能是收敛到一个**比论文低的平台**,
而不是"再训久一点就到"。⇒ 该解释不再是首选。

### 6.2 差距在**两条独立的臂上同幅出现**

| 臂 | CLIP 相对论文 |
|---|---:|
| clipscore 专家(单 reward, β=1.0, 100 upd) | **−6.3%** |
| Open3(三 reward, β=0.1, 同 100 upd 处) | **−6.1%** |

两条臂 objective 不同、β 不同、独立训练,CLIP 偏低幅度几乎一致
⇒ 指向**跨臂共同的实现层面原因**,不是单臂偶然。

### 6.3 world_size 假说:**两条可能机制均已排除**

README L323 明写论文用 **8 policy ranks**,我们用 3。逐条查其可能的作用路径:

| 候选机制 | 代码位置 | 结论 |
|---|---|---|
| advantage 归一化按 rank 做 ⇒ 归一化总体随 nproc 变 | L1216 `advantages = (avg_rewards_all - mean)/std`,其中 `avg_rewards_all` 来自 L390 的 `dist.all_gather` | **排除** —— 全局归一化,对全部 1152 样本 |
| 损失归一化因子 `wf_p` 依赖 micro-batch 大小 | L1536 `rd = tuple(range(1, y_pos.ndim))`,L1540 `wf_p = ...mean(dim=rd)` | **排除** —— `rd` 从 dim 1 起,**不含 batch 维**,逐样本计算 |
| 其余(EMA decay / 分块 / 梯度累积) | decay 只依赖 global_step;OPA 分块独立;accum=48 两侧相同,DDP 取均值 | 无 nproc 依赖 |

⇒ **world_size 假说目前没有已识别的机制。** 它仍是唯一确定的未受控差异,
但不能仅凭"存在差异"就归因。
